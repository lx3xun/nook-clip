# 两条记录行内对比（⌘ D）

核对两版配置、比较 AI 前后两次生成的代码、确认合同条款到底改了哪几个字——这类「只看差异」的活儿，传统做法是打开专门的对比软件，再分别新建两个页签把两段内容粘进去，来回切屏、还得手动对齐行号。

**NookClip 直接把对比搬到历史列表里：按 `⌘ D`，或点多选底栏 / 预览区顶栏 / 右键菜单里的「对比」，右侧预览区立刻变成红绿高亮的差异视图，字词级的改动也标得出来，还能逐块挑选保留哪一版，一键复制合并后的结果。**

---

## 1. 怎么触发

除了按快捷键 **`⌘ D`**，你也可以直接点击界面上的 3 处可见入口：**勾选 2 条记录时底部工具栏的「对比」按钮**、**右侧预览区顶栏「⋯ 更多」菜单里的「对比」**，或在**列表任意条目上点右键选择「对比两条记录」**。

| 你的操作 | NookClip 的反应 |
| :--- | :--- |
| 选中第 1 条（或未选中）触发对比 | 自动拿列表**最上面两条**记录来对比：第 2 条当「旧版」、第 1 条当「新版」（列表按最近使用时间倒序，越靠上越新） |
| 单选列表下方的第 N 条（N > 1）触发对比 | 拿**你当前选中的这条**当「旧版」，与列表**最上面最新那条**（「新版」）对比 |
| 勾选 **2 条**记录后触发对比 | 按列表里的上下位置决定新旧：靠下的那条是旧版，靠上的是新版 |
| 勾选了 **3 条及以上**再按 `⌘ D` | 不会静默塞进两条，直接提示「一次只能对比 2 条」 |
对比开始后，左侧列表会自动把参与对比的这两条**同时高亮**，右侧标题栏也标出「旧」和「新」，不会看错边。

### 对比中途想换一条记录实时比对

进入对比后**不用先退出重选**，可以直接在左侧列表切换另一侧记录，右侧差异会实时刷新：

- **按 `↑` / `↓` 或直接点击列表其它行**：固定当前带图钉标记的基准记录（默认固定靠上的「新版」），实时把另一侧换成你刚选中或点到的那一条。
- **想换固定哪一侧**：点击右侧顶栏的「旧」或「新」胶囊（或在左侧列表点一下正在对比的某一条），就能把图钉切到那一侧；也可以按住 **`⌘`（或 `⇧`）点击**另一条记录，把刚看的这条固定下来与新点的那条对比。

### 想退出对比

- 再按一次 **`⌘ D`**，或
- 按 **`Esc`**（对比态优先于其它退出层级，一按就回到普通预览），或
- 点击右侧对比顶栏右上角的 **`×`**，或左侧底栏的 **「退出对比」**。

## 2. 差异是怎么标出来的

NookClip 用两层高亮回答两个不同的问题，缺一不可：

1. **整行底色**回答「哪些行变了」——红色底是删除的行，绿色底是新增的行。
2. **行内深底色**回答「这一行里到底哪几个字变了」——只在真正改动的那几个词上加深，其余部分保持原样。

为了让红绿色弱的人也能一眼分辨，删除的部分**额外加删除线**，新增的部分**额外加粗**，不靠颜色单打独斗。

几个典型场景的识别精度：

| 你改的地方 | 会被精确标出的部分 |
| :--- | :--- |
| 合同金额 `10000` → `12000` | 只有数字本身，前后的「合同金额：」等文字不会跟着变红 |
| 变量名 `maxRetryCount` → `maxRetryTotal` | 只有 `Count` / `Total`，前面的 `maxRetry` 视为未改动 |
| 中文标点 `。` → `，` | 单个标点也能定位出来 |
| YAML 配置 `port: 8080` → `port: 9090` | 只有 `8080` / `9090`，键名 `port` 保持中性 |
| 中英文混排、emoji | 按字符边界切分，不会把一个汉字或一个表情从中间劈开 |

---

## 3. 三种看差异的视图

右侧顶部可以在三种模式之间切换：

- **行内（默认）**：删除行和新增行上下相邻，直接在一屏里读完整上下文，适合「只改了几处」的场景。
- **左右**：左边只放旧版行、右边只放新版行，适合「整段被改写」的场景。
- **只看差异**：把连续超过一段的「未改动内容」折叠成一行「… 跳过 N 行未改动内容」，改动点密集排列，适合几千行的长文件。

## 4. 逐块挑选保留哪一版

每一处改动都是一个独立的「块」，块头固定显示三个按钮：

| 按钮 | 效果 |
| :--- | :--- |
| **保留新**（默认） | 这一块用新版的写法 |
| **保留旧** | 这一块退回旧版的写法 |
| **两者都留** | 旧版这段和新版这段都保留（先后顺序：旧在前、新在后） |

顶部提供「全部 → 保留新 / 保留旧」快捷按钮，可一键将整份文档统一归到某一版。

---

## 5. 复制或粘贴合并后的版本

右侧底部固定显示「合并版 N 行」和两个出口：

- **`⌘ C` 复制合并版**：把按你逐块选择拼好的完整结果写入剪贴板，可以直接粘到任何地方。
- **`⏎` 粘贴合并版**：直接贴进你刚才切换前的那个窗口，并收起面板。

> 💡 如果对比的内容里有敏感信息（API 密钥、密码等），复制合并版同样会走敏感保护：剪贴板 30 秒后自动清除，和普通复制一致。

## 6. 键盘一览（对比态内）

| 快捷键 | 作用 |
| :--- | :--- |
| **`⌘ D`** | 开始对比 / 退出对比 |
| **`↑`** / **`↓`**（或点击列表其它行） | 固定基准侧不变，实时切换另一侧记录并刷新差异（按 `⇧ ↑` / `⇧ ↓` 或 `⌘ 点击` 则以当前游标行作为新基准） |
| **`⌥ ↑`** / **`⌥ ↓`** | 跳到上一处 / 下一处改动（右侧会自动滚到那一块并描边提示） |
| **`⌘ C`** | 复制合并版 |
| **`⏎`** | 粘贴合并版 |
| **`Esc`** | 退出对比（把光标移回列表、继续翻历史） |

## 7. 边界情况：什么能对比、什么不能

| 情况 | 行为 |
| :--- | :--- |
| 两条内容**完全相同** | 仍然进入对比态，明确告诉你「两段内容完全相同」，不用怀疑按键没生效 |
| 图片、文件条目 | 如果它们做过 OCR，就对比 OCR 出来的文字，并在标题栏标出「OCR 文本」 |
| 图片、文件没有 OCR 文字 | 提示「所选条目没有可比对的文本」，不进入对比态 |
| 敏感条目（加密存储） | 需要先解锁；解锁失败会明确提示「无法解密，暂时不能对比」，**绝不会拿掩码星号去和明文比对** |
| 超长文本 | 超过上限时标题栏标出「已截断」，仍然可以正常复制合并版 |
| 列表不足 2 条记录 | 提示「至少需要 2 条记录才能对比」 |

---

## 8. 两个可选开关

顶部有两个开关，都默认关闭：

- **忽略空白**：把缩进、空格差异视为没变。格式化过一遍的代码、从表格里复制出来的文本，打开它才能看到真正的逻辑改动。
  > 为什么默认关闭：一键对比的价值就是「到底改了什么」。如果默认把空格差异藏起来，很容易误以为内容没变。
- **忽略大小写**：只比较字母内容，不区分大小写。

两个开关一改，差异结果和合并版会同时重算，不会出现「上面按新规则算、下面按旧规则拼」的错位。
