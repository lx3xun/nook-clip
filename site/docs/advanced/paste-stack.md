# 顺序粘贴栈（Paste Stack）

顺序粘贴栈是 NookClip 最受欢迎的高阶效率功能之一。

在日常办公中，我们经常遇到这样的场景：需要把网页或表格里的姓名、电话、邮箱、地址 4 段内容，分别填入系统表单的 4 个输入框中。传统做法是：复制一项 → 切屏粘贴一项 → 切屏再复制下一项……来回切换应用多次，极其繁琐且容易贴错。

**有了顺序粘贴栈，你只需要一口气把所有内容复制完，然后切到目标窗口按原生的 `⌘ V` 连击即可逐条贴出！**

---

## 三种启动方式

### 方式一：从已有历史中多选启动（最常用）

如果你要粘贴的内容已经在 NookClip 历史记录中了：

1. 按 `⌘ ⇧ V` 呼出主面板。
2. 按住 `Shift` 配合上下键，或者用鼠标按住整段拖拽勾选你要用的那几条内容。
3. 按下快捷键 **`⌥ ⏎`**（Option + 回车）。
4. 屏幕底部立刻升起一个小巧的悬浮队列浮窗，顺序粘贴栈启动成功！

> 💡 **先进先出顺序**：NookClip 足够聪明，它会按照你**当初复制的先后时间顺序**（最早复制的排在第一位）排列队列，与主界面中“最新记录排在最上”相反，完全符合你的直觉。

### 方式二：边复制边进栈（全局录制模式）

如果你准备从一篇长文章或网页中提取多段散落的内容：

1. 在任意地方按下全局快捷键 **`⌃ ⌥ V`**（Control + Option + V）开启录制模式。
2. 屏幕底部出现空队列浮窗。
3. 接下来，你只需在源网页或文档里正常选中文本按 **`⌘ C`**。每按一次，屏幕上就会有一张小卡片伴随平滑动画“飞入”浮窗队列底部。
4. 复制完毕后，直接切换到目标窗口开始粘贴，不需要手动关掉录制。


### 方式三：复制表格或收件信息自动拆解（连续填表）

当你复制一段 Excel 表格、多列文本、键值对或收件人信息（如「张三 13800138000 北京市朝阳区…」）时：

1. 光标附近会自动浮现一枚 **「连续填表」** 轻量胶囊提示，显示识别出的类型与拆解项数。
2. 点击胶囊上的 **「连续填表」** 按钮（或直接按 **`⌥ ⏎`**），NookClip 会把整段文本按字段拆成多条并直接装入顺序粘贴栈。
3. 也可以在主面板里单选这类结构化条目后按 **`⌥ ⏎`** 直接拆解入栈（普通文本单选按 `⌥ ⏎` 仍为纯文本粘贴）。
4. 若不需要自动提示，可在 **「设置 → 记录 → 连续填表」** 中关闭。

## 怎么粘贴与使用

队列建立好之后，你甚至**不需要**再去碰 NookClip：

1. 切换到你的目标应用（如 Excel、飞书、代码编辑器或在线表单）。
2. 将光标定位在第一个输入框，直接按系统原生的 **`⌘ V`**（Command + V）——第一条内容立刻贴入！
3. 按 `Tab` 切换到下一个输入框，再按一次 **`⌘ V`**——第二条内容贴入！
4. 如此往复，直到所有条目全部贴完，浮窗自动完成使命并退出。

### 浮窗上的状态指示与交互

- **进度指示**：浮窗右侧明确显示 `已贴 2 / 5` 进度。
- **当前待贴项**：行首带 **`▶`** 绿色箭头的条目就是当前剪贴板里的下一项。
- **已贴项标记**：已经贴出的条目会自动变为灰色并打上删除线勾选，清晰知道贴到了哪里。
- **插队点按**：用鼠标点某一行，可以仅改变高亮焦点而不做粘贴；也可以直接点某行右侧的 **「粘贴」** 按钮立刻贴出那特定的一条。
- **不抢焦点**：浮窗完全不会夺走当前文本框的输入焦点，打字和光标切换丝毫不受影响。
- **随意拖动**：按住浮窗空白处可以把它拖到屏幕任意角落，软件会记住你的位置偏好。

---

## 随时退出与中断

如果粘贴到一半不想继续了：

- 在任何窗口中直接按 **`Esc`** 键，浮窗立即收起退出。
- 或者再次按下 **`⌃ ⌥ V`** 即可主动关闭队列。
- 也可以直接点击浮窗右上角的关闭按钮。
