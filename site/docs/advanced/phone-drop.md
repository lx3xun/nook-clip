# 手机互传（Phone Drop）

想把手边 Mac 上一段很长的文字、一张截图或一个文件发到手机上，过去得先发给自己一条聊天消息、登录网盘，或者两台设备都装上同一个 App。用 Android 手机、或没有登录同一个账号时，这条链路经常干脆走不通。

**手机互传**把这件事变成「扫一下就完事」：在 Mac 上选中一条记录，点「手机互传」，手机用系统相机扫一下二维码，就能在浏览器里直接查看并复制电脑上的长文本、下载原图或文件；手机上的文字和照片也能直接传回 Mac 剪贴板。**手机不用装任何 App，网页自动适配简中 / 繁中 / 英文，数据只在同一个局域网里走，不经过任何云服务器。**

---

## 1. 怎么触发 / 它怎么工作

1. 在 NookClip 主面板里选中任意一条记录（文本、代码、图片、文件都行）。
2. 点开预览区顶栏右侧的**「⋯ 更多」**菜单，选择**「手机互传」**。
3. 弹出的窗口会显示一个二维码，并附上「局域网地址」和实时倒计时。默认 **5 分钟**有效。
4. 手机连到和电脑**同一个 Wi-Fi**，用系统相机（或任意扫码工具）扫一扫，就能在手机浏览器里打开这个页面，直接开始收发。

> 如果选中的是一条网址，二维码默认会给出「链接二维码」，并提示你可以切换成「双向互传」模式：既能打开这个网址，也能继续往电脑回传内容。

与此同时，电脑会在本机临时起一个小服务、并生成一个**一次性随机令牌**，只有扫到这个二维码的设备才能访问。**传输期间请保持此互传界面打开**——一旦关闭弹窗、切走面板或倒计时结束，服务会立即停止，连接随即断开并释放端口。

---

## 2. 手机端能做什么

手机浏览器里的页面分上下两部分：上面看电脑发来的内容，下面把手机内容发回电脑。

**下发（电脑 → 手机）**

| 内容类型 | 手机端操作 |
| :--- | :--- |
| 长文本 / 代码 | 完整查看，单击「复制」即复制到手机剪贴板 |
| 图片 | 查看原图，可长按或点「下载」保存到手机相册 |
| 文件 | 点「下载」保存到手机 |

**上行（手机 → 电脑）**

| 内容类型 | 手机端操作 |
| :--- | :--- |
| 文字 | 在页面底部的输入框里输入文字，点「发送」，电脑剪贴板立刻收到并存入历史列表 |
| 图片 / 文件 | 从相册选择图片，或点选择文件，选中后一键发送回电脑 |

电脑收到回传内容时，会弹出一句轻提示「已收到来自移动端的剪贴内容」，并自动记入历史，之后照着平时的习惯使用即可。

## 3. 安全边界

- **只在同一局域网内**：电脑和手机必须连在同一个 Wi-Fi / 局域网，跨网络无法访问。
- **一次性随机令牌**：每次开启都会生成新的随机令牌，链接只在本次有效，别人拿到旧二维码也打不开。
- **5 分钟自动失效**：默认倒计时结束，服务自动关闭；也可以随时点「停止分享」立即结束。
- **关闭即释放端口**：关闭弹窗或倒计时结束时，临时服务立即停止，端口随之释放，不做常驻监听。
- **单次上传 50MB 上限**：手机回传的单个文件或图片不超过 50MB，避免大文件占满内存。
- **不经过任何云服务器**：所有数据传输都发生在你的电脑和手机之间，不落任何第三方服务器，也不需要账号登录。

## 4. 常见问题

**Q：手机扫码后打不开页面？**
先确认电脑和手机连的是同一个 Wi-Fi。如果电脑当前没有局域网连接，NookClip 会提示「请先连接 Wi-Fi 或局域网」，连上后再点一次「手机互传」即可。

**Q：关掉面板后还能扫码吗？**
不能。互传界面下方会提示「传输期间请保持此界面打开，关闭或切走将立即断开连接」。一旦关闭弹窗、收起主面板或倒计时结束，临时服务会立刻停止、端口释放，旧的二维码和链接都会断开失效。需要时重新点「手机互传」生成新的二维码。

**Q：手机上传后电脑没反应？**
确认电脑上的互传二维码界面仍保持打开（未关闭或切走），且手机和电脑在同一网络下。上传成功后电脑会提示「已收到来自移动端的剪贴内容」，并自动存入历史列表。

**Q：手机需要装 App 吗？**
不需要。手机打开的是网页，用系统相机扫码即可，iOS 和 Android 都适用。
