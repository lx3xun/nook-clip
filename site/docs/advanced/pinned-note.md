# 屏幕置顶贴条（Pinned Note）

日常编程、写作或设计时，经常需要对着参考文档“照猫画虎”，比如照着一段代码样例敲代码、照着设计稿中的色值标注调样式、或者照着截图中的文字手动录入数据。如果频繁在多个全屏窗口之间切来切去，注意力很容易被打碎。

NookClip 的 **屏幕置顶贴条** 功能，可以把任意一条记录像便签纸一样“钉”在屏幕最顶层。

---

## 1. 钉到屏幕上（`⌘ P`）

1. 按 `⌘ ⇧ V` 呼出 NookClip 主面板。
2. 选中你要参考的代码、纯文本、图片或色值记录。
3. 按下快捷键 **`⌘ P`**（Command + P）。
4. 刚才的内容立即变成一个半透明的小巧置顶贴条，始终固定在所有软件的最上方。

> 💡 **原位替换机制**：如果你在 NookClip 里对另一条记录再次按下 `⌘ P`，它会直接原位替换掉当前屏幕上的贴条，保证屏幕整洁，不会留下一堆杂乱的临时小窗。

---

## 2. 贴条实用特性

### 保持语法高亮与富媒体形态
- **代码贴条**：钉住的代码保留彩色代码语法高亮，字号适中，易于对照阅读。
- **图片贴条**：钉住截图时，右上角提供快捷按钮，可以直接提取截图中识别到的文字。
- **色值贴条**：直观展示颜色色块和 HEX / RGB 色值。

### 调节透明度与折叠
- 按住 **`⌥`（Option）配合鼠标滚轮**（或悬停拖动控制条滑块），可在 `20% ~ 100%` 之间调节半透明度，即使盖住底层窗口也能看清下方文字。
- 点击控制条上的折叠按钮，可将贴条收起为单行标题栏，需要时再展开。
### 鼠标点击穿透（锁定）
当你需要边看贴条边在贴条下方的编辑器里敲键盘或点击鼠标时，为了防止鼠标误触贴条：

1. 点击贴条右上角的 **小锁图标**，贴条将进入「鼠标穿透模式」。
2. 此时贴条如同空气，鼠标的点击和滚动动作会直接透过它，作用在它正下方的软件上。
3. **如何恢复点击**：按下全局快捷键 **`⌘ ⌥ P`**（Command + Option + P），或者点击贴条角落解锁图标，即可退出穿透模式。

### 内联编辑草稿
- 贴条不仅可以看，还能直接编辑。在贴条文本区域点一下，即可当作临时草稿修改文字、补充要点。
- 修改完成后，点击底部的保存按钮，可以直接作为一条新记录存回剪贴板历史中。

---

## 3. 关闭贴条

- 点击贴条左上角或右上角的关闭按钮 `✕`；
- 选中贴条时直接按键盘的 **`Esc`** 键即可关闭。
