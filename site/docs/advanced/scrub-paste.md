# 语义脱敏粘贴与还原（Scrub & Unscrub）

日常工作中，我们经常需要把带有配置信息、接口报错或数据库连接串的代码发给 AI（如 ChatGPT、Claude、DeepSeek）或同事求助。如果不小心把真实的 API Key、数据库密码、内部 Token 或私人手机号一起发了出去，可能会引发严重的安全泄漏事故。

NookClip 提供了首创的 **「语义脱敏粘贴与闭环还原」** 功能，让你无需手动把密码改成 `***`，一键安全提问。

---

## 1. 语义脱敏粘贴（`⌃ ⏎`）

当你选中一条可能包含敏感信息的记录时：

- 按下快捷键 **`⌃ ⏎`**（Control + 回车）。
- NookClip 会在毫秒级内自动检测其中的敏感数据，并把它们替换为具有业务语义的可读占位符（例如 `<API_KEY_1>`、`<PASSWORD_1>`、`<EMAIL_1>`），然后再粘贴到前台输入框中。

### 为什么叫做“语义”脱敏？

传统的脱敏只是粗暴地打上星号 `***`，这会导致代码语法破损、AI 无法理解变量指代关系。

NookClip 的占位符保留了结构语义：
```json
// 原始文本（极度危险）：
{
  "api_key": "sk-proj-982347102938471092834710",
  "db_url": "postgres://admin:secret123@10.0.0.5:5432/prod"
}

// 经过 ⌃ ⏎ 脱敏粘贴后的文本（安全合规，AI 依然能看懂）：
{
  "api_key": "<API_KEY_1>",
  "db_url": "postgres://admin:<PASSWORD_1>@10.0.0.5:5432/prod"
}
```

### 严谨的算法与低误伤

内置底层 Rust 算法，支持识别包括 API 密钥、数据库连接串、私钥凭证、邮箱、手机号、身份证、银行卡等 **19 类** 常见敏感模式。
针对容易误伤的类型，内置了工业级数学校验：
- 银行卡经过 **Luhn** 校验；
- 身份证经过 **ISO 7064** 校验；
- 像 `127.0.0.1` 本地回环地址、`/Users/Shared` 等日常开发文本绝不会被误当作敏感信息。
- 支持在「设置 → 隐私」中开启**离线人名与地址识别**（调用 macOS 本地语言模型，全程不联网），以及添加**自定义脱敏规则**（支持关键词或正则 + 自定义占位符标签）。

---

## 2. 闭环还原真实值（`⌃ ⇧ ⏎`）

当你把脱敏后的代码交给 AI 调试后，AI 修复了 Bug 并返回了代码。AI 产出的代码里通常依然保留着 `<API_KEY_1>` 这类占位符。

你不需要手动挨个把密码抄回去：

1. 复制 AI 修复好的这段代码。
2. 呼出 NookClip 选中刚才复制的内容（预览区会贴心提示：`检测到 N 个脱敏占位符`）。
3. 按下快捷键 **`⌃ ⇧ ⏎`**（Control + Shift + 回车）。
4. NookClip 会自动把代码里的所有 `<API_KEY_1>` 原位替换回你真实的密钥，并直接粘贴到你的开发工具中！

---

## 3. 粘贴前温和提醒

选中一条含敏感信息的记录时，NookClip 预览窗格顶部会显示一行温和的提示栏：
> 🛡️ **检测到 2 处敏感信息（邮箱、API Key）**  [按 ⌃ ⏎ 脱敏粘贴]

- **绝不打扰**：它不会弹出弹窗阻断你的操作，如果你确实需要粘贴真实值，直接敲常规回车 `⏎` 依然可以原样贴出。
- **开关自由**：可以在「设置 → 隐私」中根据个人习惯关闭此提醒。

---

## 4. 极致的安全性设计

- **映射关系仅驻留内存**：占位符与真实密码的映射表**仅保存在本机运行内存中**，绝对不会写入数据库、不会写入磁盘文件、更不会上传网络。
- **自动销毁**：系统闲置 30 分钟后，内存中的映射表会自动销毁。
- **随时清空**：前往「设置 → 隐私」，可以随时查看当前内存映射数并点击一键清空。
