# 终端安全粘贴护栏（Terminal Safe-Paste）

从网页复制一段命令，粘进终端，结果末尾那个看不见的换行让它**当场回车执行**了——这是程序员最经典的噩梦之一：`rm -rf` 多跑一行、`sudo` 命令没看清就跑了。

NookClip 的**终端安全粘贴护栏**会先判断「你要粘进去的这个应用是不是终端」，再判断「这段内容一落地会不会直接执行」，需要时先拦一下。

---

## 1. 它怎么判断

只看两件事，毫秒级完成，全程本地、不联网：

**第一件：目标应用是不是终端**

三层识别，覆盖新老终端：

| 识别方式 | 覆盖范围 |
| :--- | :--- |
| 内置名单精确匹配 | Terminal、iTerm2、Warp、Ghostty、kitty、Alacritty、WezTerm、Tabby、Hyper、Otty、Orca、Wave、Rio、Contour、Termius、Prompt、Blink、Royal TSX、SecureCRT、FinalShell、WindTerm、Electerm、ExtraTerm、Zoc、ServerCat、Xterminal、MacTerm、Coressh、Upterm、OrbStack、UTM、Docker 等 |
| 名称关键词兜底 | 应用名里含 `terminal`、`iterm`、`waveterm`、`finalshell`、`windterm`、`securecrt` 等特征词，即使没登记过也会被识别 |
| 内置终端保护（可关） | VS Code、VSCode Insiders、VSCodium、Cursor、Windsurf、Trae、Zed、Xcode、Nova、Sublime Text、JetBrains 全家桶、DeepSeek Harness、WebCodex、WorkBuddy 等带终端面板的编辑器与 AI 工具 |

> **关于编辑器内置终端**：系统层面拿不到「你现在是不是在看终端面板」这个信息，所以编辑器里默认**只拦多行与高危命令**，粘普通代码不会弹窗；如果觉得打扰，可在「设置 → 粘贴 → 终端安全粘贴护栏」里关掉「内置终端保护」，关掉后这些应用完全不再介入。

**第二件：内容危不危险**

| 情况 | 处理方式 |
| :--- | :--- |
| 单行、无高危词、末尾带换行 | **静默**去掉末尾回车，粘贴后一句轻提示，不弹窗 |
| 多行命令 | **弹窗**确认，列出命中的风险类型 |
| 命中高危词（`sudo` / `rm -rf` / `rm -r -f` / `find -delete` / `mkfs` / `dd of=/dev/` / `curl \| sh` / `chmod 777` / `git push --force` / `git reset --hard` / `git clean -fd` / `DROP TABLE` / `DROP DATABASE` / 关机重启 / `killall -9` / fork 炸弹） | **弹窗**确认 |
| 目标不是终端 | **完全不介入**，零延迟、零提示 |
| 内容是图片或文件 | 不参与命令判定，按原样粘贴 |

---

## 2. 弹窗里的三个选择

当它决定要拦你一下时，会给你三个按钮：

### 安全粘贴（推荐）

把多行命令用 ` && ` **串成一行**，粘贴后停在终端输入行，**不会自动回车执行**。你可以先扫一眼命令、用方向键修改局部，或按 `⌃C` 放弃，确认无误后再亲自按 Return 执行。
### 原样粘贴

完全按剪贴板原文粘贴（包括末尾换行和高危内容）。适合你完全确定自己在干什么的时候。

### 取消

什么都不做。剪贴板不变，终端不变，命令不会执行。

---

## 3. 一个重要的安全边界：不会替你改写命令

如果这段内容**无法安全串成一行**，NookClip 会退化成「只去掉末尾换行」，绝不强行拼接。

以下情况会被判定为不可安全串联：

- 含 heredoc（`<<EOF`）
- 含 `#` 注释行
- 行尾是 `|`、`||`、`&`、`;`、`\`、`&&` 这类显式连接符

**原因**：这些地方的换行是命令语法的一部分。比如一个 `for` 循环，强行压成一行会改变命令语义。宁可让你逐行确认，也不能替你改写命令。

---

## 4. 顺序粘贴栈也受保护

顺序粘贴栈（`⌥ ⏎`）运行时，如果你在终端里点某一条的「粘贴」按钮，护栏同样生效。

点「取消」时，**队列现场会原样保留**——高亮位置不动、进度不推进，不会让你以为已经往下走了一格。

---

## 5. 什么时候它会主动放行

以下情况 NookClip 完全不参与，走原有粘贴路径：

- 目标应用不是已知终端，名称里也没有终端特征词
- 目标是编辑器 / AI 工具且「内置终端保护」已关掉
- 内容是图片、文件（只有文本和链接可能是一条命令）
- 文本为空
- 你在设置里关掉了「终端安全粘贴」总开关
- 拿不到目标前台应用的信息（宁可不介入，也不误判）

---

## 6. 关掉它

「设置 → 粘贴 → 终端安全粘贴护栏」两个开关：

| 开关 | 作用 |
| :--- | :--- |
| 终端安全粘贴 | 总开关，关掉后所有粘贴入口同时失效 |
| 内置终端保护 | 只在总开关打开时出现；关掉后 VS Code、Cursor、Xcode、JetBrains 等编辑器与 AI 工具不再参与拦截 |

**建议保持开启**。这个功能不需要你学习任何操作：你只会在即将踩坑的那一刻看到它，平时完全无感。
