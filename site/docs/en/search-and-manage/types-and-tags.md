# Type Slots & Tags

In addition to chronological browsing and keyword search, NookClip provides **8 Fixed Category Slots** and **Custom Tags** to keep your history organized.

---

## 1. 8 Fixed Category Slots

The filter bar features 8 fixed slots whose positions never shift:

1. **Starred**: Favorited items (`⌘ S`) — permanently exempt from auto-cleanup limits.
2. **Images**: Screenshots, photos, and graphics.
3. **Text**: Plain and rich text passages.
4. **Links**: URLs with preview cards and instant QR codes.
5. **Code**: Source code snippets with syntax highlighting.
6. **Files**: Files copied from Finder (with missing-file warnings if moved or deleted).
7. **Colors**: Hex / RGB color codes (`#1677FF`) with live color swatches.
8. **Trash**: Recently deleted items that can be restored or permanently emptied.

### Keyboard Category Switching

- **`⌘ ]`** (Command + Right Bracket): Jump to the next non-empty category.
- **`⌘ [`** (Command + Left Bracket): Jump to the previous non-empty category.
- Empty categories are skipped automatically so you never land on a blank list.

---

## 2. Expand & Collapse the Filter Drawer (`⌘ ↓`)

- Press **`⌘ ↓`** (Command + Down Arrow) to expand or collapse the Filter Drawer below the search bar.
- Press **`⌘ F`** to focus the search box and expand the Filter Drawer simultaneously.
- The drawer shows item counts per category along with all your custom tags.

---

## 3. Custom Tags (`⌘ L`)

Tags let you group items across different types (for example, tagging a URL, a code snippet, and a screenshot with `#ProjectA`).

### Adding Tags
1. Select one or more entries.
2. Press **`⌘ L`** (Command + L).
3. Type a tag name and press `Return` (an entry can have multiple tags).

### Combining Category + Tag Filters
- Click any tag in the Filter Drawer to filter by that tag, or combine it with a category slot (e.g. **Links** + `#Work`).
- **Backspace Unwind (`⌫`)**: When the search box is focused and empty, pressing **`⌫`** removes active filters from the inside out: first the active tag, then the active category.
