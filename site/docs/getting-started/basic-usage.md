# 基础使用

NookClip 的核心设计理念是**“全键盘流”**与**“零打扰”**：你日常所有的剪贴板查找和粘贴操作，都不需要离开键盘或伸手去摸鼠标。

---

## 1. 呼出与隐藏面板

- **呼出主面板**：在任意应用中按下全局快捷键 **`⌘ ⇧ V`**（Command + Shift + V）。
- **鼠标呼出**：点击屏幕右上角菜单栏的 NookClip 图标。
- **自动隐藏**：在面板外任意位置点一下鼠标，或者按 **`Esc`** 键，面板会自动退出并隐藏，不会残留抢占屏幕。

---

## 2. 打字直接搜（Type-to-Search）

呼出面板后，你**不需要**用鼠标去点顶部的搜索框，也**不需要**按快捷键聚焦：

- **直接敲键盘打字**：键盘输入的英文字母、数字或汉字拼音，会直接流入搜索框开始全文检索。
- **即时高亮**：匹配到的关键词会在列表条目与右侧预览区实时标黄高亮。
- **清空搜索词**：按 `Esc` 键或搜索框内的退格键 `⌫` 可以迅速清空检索内容，恢复完整历史列表。

---

## 3. 键盘上下选择

- **`↑` / `↓` 方向键**：在历史记录列表中上下移动当前高亮项。
- **长按连续滚动**：按住方向键不放可以快速滑动浏览，滑到底部时会自动加载更早的记录（触底自动扩页）。
- **右侧即时预览**：高亮选中某条记录时，右侧预览窗格会立即展示该条目完整内容、创建时间、来源应用图标以及字符数等详情。

---

## 4. 四种基础粘贴操作

选中想要的某条历史记录后，根据不同场景你可以选择不同的按键：

| 按键操作 | 行为效果 | 适用场景 |
| :--- | :--- | :--- |
| **`⏎` (回车)** | **直接粘贴**：面板立刻收起，自动将内容贴入当前输入框 | 最常用的日常粘贴 |
| **`⌥ ⏎` (Option + 回车)** | **纯文本粘贴 / 顺序粘贴栈**：单选普通文本时自动剥离富文本格式；多选或单选表格/收件信息时启动顺序粘贴栈 | 从网页复制代码或带格式文本到编辑器，或连续填表 |
| **`⌘ ⏎` (Command + 回车)** | **粘贴并保持面板打开**：贴出内容但面板不收起 | 连续在两个应用间比对数据，或者在同一表单连续填多项 |
| **`⌘ C`** | **重新复制**：将选中项装入系统剪贴板，但不做粘贴动作 | 仅更新剪贴板内容，稍后手动粘贴 |

> 💡 **划词复制**：除了按 `⌘ C` 复制整条记录，你也可以用鼠标在右侧预览窗格里选中国定的一小段文字，然后按 `⌘ C` 提取局部内容。

---

## 5. 分层退出（Esc 机制）

为了防止用户误触退出按键丢失刚刚输入的搜索词或筛选条件，NookClip 的 **`Esc`** 键采用了智能的**分层返回机制**：

1. 打开了「重命名别名」或「标签编辑」浮层时，按 `Esc` 先关闭浮层；
2. 展开了搜索框下方的筛选面板时，按 `Esc` 收起筛选面板；
3. 处于两条记录对比视图（`⌘ D`）时，按 `Esc` 退出对比；
4. 处于批量多选状态时，按 `Esc` 退出多选；
5. 有搜索词、标签筛选、类型筛选或时间分组条件时，按 `Esc` 逐层清空复位；
6. 以上状态均已复位时，按 `Esc` 收起主面板。
