# 下载、安装与首次配置

本文将指导你下载安装 NookClip 并完成首次使用所必需的系统权限设置。

---

## 1. 下载与安装

### 推荐方式：下载通用安装包（DMG）

NookClip 安装包为通用二进制文件（Universal Binary），原生支持苹果芯片（M1/M2/M3/M4 系列等 Apple Silicon）以及 Intel 芯片的 Mac 电脑。

- **GitHub 发行版**：[前往 GitHub Releases 下载最新版本](https://github.com/lx3xun/nook-clip/releases/latest)
- **国内加速镜像**：[前往 Gitee 发行版下载](https://gitee.com/lx3xun/nook-clip/releases)

### 安装步骤

1. 双击打开下载好的 `NookClip-<版本号>.dmg` 镜像文件。
2. 将 **NookClip.app** 图标拖拽到 **Applications（应用程序）** 文件夹。
3. 在应用程序中找到 NookClip 双击启动。

---

## 2. 首次启动与安全提示处理

因为 NookClip 是开源免费软件，未加入收费的苹果官方公证流程，首次打开时 macOS 的安全机制（Gatekeeper）可能会拦截启动。这属于正常安全机制，按以下方式处理即可：

### 情况 A：提示「无法打开，因为无法验证开发者」

1. 打开访达（Finder），进入「应用程序」文件夹。
2. 找到 **NookClip**，**按住 Control 键点按（或鼠标右键）**。
3. 在弹出的右键菜单中点击 **「打开」**。
4. 系统会弹出二次确认框，再次点击 **「打开」** 即可。只需这样操作一次，以后直接双击即可启动。

### 情况 B：提示「已损坏，移到废纸篓」

如果系统提示文件已损坏，这是 macOS 对从浏览器下载的文件的隔离标记（Quarantine）导致的，无需重装。

1. 按 `⌘ 空格` 呼出聚焦搜索，输入并打开 **终端（Terminal）**。
2. 复制并执行以下命令（按回车执行）：
   ```bash
   xattr -cr /Applications/NookClip.app
   ```
3. 重新在访达中双击打开 NookClip 即可正常启动。

## 3. 必须的系统权限配置

为了实现「在面板里敲回车就能把选中的记录自动粘贴到你当前的光标处」，NookClip 需要开启 macOS 的 **辅助功能（Accessibility）** 权限。

> 💡 **隐私说明**：辅助功能权限仅用于在选中历史记录时向系统发送一次标准的粘贴按键信号。NookClip 没有后台上传行为，也不会监听你的全局击键。

### 开启步骤

1. 打开系统的 **「系统设置」**。
2. 在左侧菜单点击 **「隐私与安全性」**，然后在右侧找到 **「辅助功能」**。
3. 在列表中找到 **NookClip**，将其右侧的开关打开（允许）。如果列表中没有，可以点击下方的 `[+]` 号，在「应用程序」里手动添加 NookClip。

> ⚠️ **小贴士**：如果日后升级新版本后发现回车无法自动粘贴，通常是因为 macOS 认为软件签名变更了。只需在「辅助功能」列表中选中 NookClip，点下方的 `[-]` 移除它，然后再点 `[+]` 重新添加并勾选即可恢复。

---

## 4. 完成首次配置

权限开启后，NookClip 会常驻在菜单栏右上角（图标类似一个小图钉）。

- 按全局默认快捷键 **`⌘ ⇧ V`**（Command + Shift + V）即可呼出主面板。
- 如果默认快捷键与你的其他常用软件冲突，可以点击菜单栏图标选择「设置」，在「粘贴」标签页中录制你习惯的按键。
