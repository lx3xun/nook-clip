# 完整快捷键速查表

熟练使用快捷键是发挥 NookClip 极限生产力的核心。以下是目前支持的所有默认键盘操作：

---

## 1. 全局呼出与录制

| 快捷键 | 功能说明 | 备注 |
| :--- | :--- | :--- |
| **`⌘ ⇧ V`** | 全局呼出 / 隐藏主面板 | 可在「设置 → 粘贴」中自由自定义录制按键 |
| **`⌃ ⌥ V`** | 启动 / 结束顺序粘贴栈录制 | 开启后可一边复制一边攒队列，再次按下结束 |
| **`⌘ ⌥ P`** | 恢复屏幕置顶贴条的鼠标点击 | 退出贴条的“鼠标点击穿透锁定”模式 |

---

## 2. 浏览与多选

| 快捷键 | 功能说明 | 备注 |
| :--- | :--- | :--- |
| **`↑` / `↓`** | 上下移动当前高亮项 | 长按快速连续滚动，滚动触底自动加载下一页；对比态内固定基准记录并实时切换另一侧记录 |
| **`⇧ ↑` / `⇧ ↓`** | 连续扩展批量多选 | 从当前选中项开始向上或向下圈选 |
| **鼠标上下拖动** | 整段框选条目 | 按住 Shift 拖动可追加勾选，拖到边缘自动滚动 |
| **`⌘ + 鼠标点击`** | 点选或取消选中单个条目 | 适合多选不连续的记录 |
| **`⌘ T`** | 循环跳转到下一个时间分组 | 例如在“今天”、“昨天”、“更早”之间快速跳转 |
| **`⌥ ↑` / `⌥ ↓`** | 对比态内跳到上一处 / 下一处改动 | 仅在按 `⌘ D` 进入的对比视图内生效，右侧自动滚到该块并描边 |

---

## 3. 粘贴与复制动作

| 快捷键 | 功能说明 | 备注 |
| :--- | :--- | :--- |
| **`⏎` (回车)** | 粘贴并收起面板 | 最常用的粘贴；多选态下为批量合并粘贴；输入应用名时为启动应用 |
| **`⌥ ⏎`** | 纯文本粘贴 / 连续填表 | 单选普通文本时剔除富文本格式；**多选状态下或单选表格/收件信息时启动顺序粘贴栈** |
| **`⌃ ⏎`** | 语义脱敏粘贴 | 将 API 密钥、密码等敏感信息替换为可读占位符再粘贴 |
| **`⌃ ⇧ ⏎`** | 还原真实值粘贴 | 将剪贴板中的占位符原位替换回真实密码后再粘贴 |
| **`⌘ ⏎`** | 粘贴且保持面板开启 | 贴出选中的内容，但主面板不关闭，适合连续填表与比对 |
| **`⌘ C`** | 重新复制到系统剪贴板 | 仅更新剪贴板内容，不执行前台粘贴动作 |
| **`⌘ D`** | 对比两条记录 / 退出对比 | 也可点预览顶栏、勾选 2 条时的底部工具栏或右键菜单触发；勾选 2 条比这两条，单选第 N 条时与最上面最新那条比，选中第 1 条时直接比最上面两条 |
| **`⌘ C`（对比态内）** | 复制合并后的版本 | 按你逐块选择的「保留新/旧/都留」拼出完整文本再写入剪贴板 |
| **`⏎`（对比态内）** | 粘贴合并后的版本 | 直接贴进切换前的目标窗口并收起面板，与多选态的「合并粘贴」不是同一动作 |

> **自动生效、无需按键**：目标窗口是终端（Terminal / iTerm2 / Warp 等）时，粘贴多行命令或含 `sudo`、`rm -rf` 等高危内容会自动弹出安全确认窗。详见 [终端安全粘贴护栏](../advanced/terminal-safe-paste.md)。

---

## 4. 置顶、收藏与编辑

| 快捷键 | 功能说明 | 备注 |
| :--- | :--- | :--- |
| **`⌘ P`** | 将选中项钉成屏幕置顶贴条 | 悬浮置顶在所有软件最上层，再次按自动原位替换 |
| **`⌘ S`** | 收藏 / 取消收藏选中项 | 收藏的条目永久保留，免于历史条数淘汰 |
| **`⌘ R`** | 设置 / 修改自定义别名 | 留空回车可清除别名，设置后可通过别名快速检索 |
| **`⌘ L`** | 为选中项编辑或添加标签 | 弹出标签编辑浮层 |
| **`⌘ ⌫`** | 删除当前选中项或多选项 | 10 秒内按 `⌘ Z` 可撤销恢复，之后转入回收站 |
| **`⌘ Z`** | 撤销最近一次删除 | 10 秒倒计时内按下立即原位恢复 |

> **预览区顶栏已精简**：右侧常驻「钉在屏幕（`⌘ P`）」、「收藏（`⌘ S`）」与「⋯ 更多」三个按钮，「脱敏粘贴（`⌃ ⏎`）」仅在当前记录检测到敏感信息时按需出现；对比两条记录、手机互传、二维码、在访达中显示、编辑标签与删除记录等动作统一收进「⋯ 更多」菜单（附带快捷键提示）。以上所有快捷键不受影响，照常可用。

---

## 5. 搜索、分类与导航

| 快捷键 | 功能说明 | 备注 |
| :--- | :--- | :--- |
| **直接敲键盘** | 打字即时搜索 | 呼出后无需任何切换，直接按键即可检索 |
| **`⌘ F`** | 聚焦搜索框并展开筛选面板 | 自动展开类型网格与标签流 |
| **`⌘ ↓`** | 展开 / 收起筛选面板 | 在紧凑列表与分类筛选面板间切换 |
| **`⌘ ]`** | 切换到下一个有内容的分类 | 自动跳过无记录的空分类槽位 |
| **`⌘ [`** | 切换到上一个有内容的分类 | 自动跳过无记录的空分类槽位 |
| **`⌫` (退格)** | 逐层清除筛选条件 | 搜索框聚焦为空时按：先清标签，再清分类 |
| **`Esc`** | 分层智能退出 | 依次关闭浮层 → 收起筛选 → 退出对比态 → 退出多选 → 清空搜索 → 隐藏面板 |
