# 批量操作与撤销删除

为了提升大量信息处理时的流畅感，NookClip 提供了与 macOS 原生体验完全一致的多选交互，并配备了贴心的反悔机制。

---

## 1. 像在桌面一样轻松多选

你可以根据个人习惯，选择键盘或鼠标进行多选：

### 键盘快捷多选
- **`⇧ ↑` / `⇧ ↓`（Shift + 方向键）**：从当前焦点开始，连续向上或向下选定多个条目。
- **退出多选**：按一下 **`Esc`** 键即可瞬间取消选定，恢复单选状态。

### 鼠标拖拽框选（Drag Selection）
- 在列表任意区域**按住鼠标左键并上下拖动**，可以直接划过并勾选整段条目。
- **按住 Shift 拖动**：在已有选中的基础上，继续追加勾选新的区间。
- **边缘自动滚动**：当拖动鼠标触碰到列表的上方或下方边缘时，列表会自动平滑加速滚动，方便一次性多选跨屏的长列表。
- **`⌘ + 鼠标点击`**：精准点选某几个不连续的条目。

---

## 2. 批量处理的高频操作

勾选出多个条目后，底部会升起批量操作浮条（Batch Bar）：

- **批量合并粘贴（`⏎` 回车）**：
  直接按下回车键，选中的所有内容会自动以换行符（可在设置中自定义分隔符）拼接在一起，一次性粘贴到当前目标窗口。
- **启动顺序粘贴栈（`⌥ ⏎`）**：
  按下 Option + 回车，将勾选的条目排入顺序粘贴栈队列，随后逐条出牌（详见 [顺序粘贴栈指南](../advanced/paste-stack.md)）。
- **对比两条记录（`⌘ D`）**：
  当恰好勾选 **2 条**记录时，底部工具栏会出现「对比」按钮（或直接按 `⌘ D`），右侧即刻展示行级与字词级红绿差异（详见 [两条记录行内对比](../advanced/inline-diff.md)）。
- **批量打标签（`⌘ L`）与批量删除（`⌘ ⌫`）**：
  一键为多条记录管理标签，或按 Command + Delete 快速清理无用历史。
---

## 3. 误删反悔：10 秒内撤销（`⌘ Z`）

日常清理历史记录时，最担心的就是手抖按错键删掉了重要的代码或文本。

在 NookClip 中，无论是单条删除还是批量删除：
- 删除发生后，界面底部会立即出现一个 **「已删除，10 秒内按 ⌘ Z 撤销」** 的悬浮提示条，并带有清晰的倒计时进度。
- 只要在倒计时结束前按下 **`⌘ Z`**（Command + Z），刚刚删除的所有条目就会原封不动地原位恢复，甚至连条目的创建时间和标签属性也会完全保留。
- 就算超时了也不用慌，所有被删除的记录都会先进入「回收站」分类，随时可以进去恢复。
