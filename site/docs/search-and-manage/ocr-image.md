# 离线图片文字识别（OCR 与以字搜图）

日常办公中我们经常会截图，例如报错日志截图、网页数据表格截图、聊天记录截图等。图片中的文字既不能直接复制，时间一长沉入历史记录后，也很难再通过文字把当年的那张截图找出来。

NookClip 内置了苹果原生 **Vision 离线视觉识别能力**，无需任何网络，在本地即可完成高精度的文字识别。

---

## 1. 为什么设计为“按需触发”？

许多工具会在后台对你每一次复制的图片自动疯狂跑 OCR 算法，这会导致常驻内存飙升到几百兆、笔记本发烫耗电，而且绝大多数截图往往并不需要提取文字。

NookClip 采用了更优雅的 **「按需点按识别」** 策略：
- **平日零消耗**：平时复制图片时，只做原生的轻量快照存储，常驻内存保持在 ~20MB，没有任何多余后台运算。
- **需要时一触即发**：当你需要提取某张图片中的文本时，只需在图片卡片上点击 **「识别文字」** 按钮，系统在 0.2 秒内即可完成离线解析。

---

## 2. 怎么使用 OCR 提取文字

1. 在 NookClip 列表中选中某张图片历史记录。
2. 在卡片或右侧预览窗格上方，点击 **「识别文字」**（带有放大镜图标）。
3. 识别完成后，预览区会立刻展开显示格式化好的文本排版。
4. 你可以直接选中局部文字，或者点击下方的 **「复制文字」**，直接提取出识别内容。

---

## 3. 图片文字参与全局检索（以字搜图）

一张图片只要执行过一次文字识别，NookClip 就会自动将识别出来的所有词句提取出来，写入本地的 SQLite FTS5 全文索引。

这意味着：
- 下次你在搜索框里输入这张截图里的某句话（例如发票号、报错代码、人员名字）；
- 即使搜索列表里只有纯文字，这张**带有对应文字的截图卡片也会立刻被检索并高亮呈现出来**！
- 彻底解决了“只记得图里写了什么，却翻不到那张图”的痛点。
