# 全文搜索与拼音启动应用

很多剪贴板工具的历史记录越攒越多后，常常会出现“搜不出”或“搜索卡顿”的问题。NookClip 采用了高性能的 SQLite FTS5 本地全文索引技术，即使存储数万条历史记录，敲击键盘搜索也能做到毫秒级极速响应。

---

## 1. 毫秒级全文搜索

呼出面板后，直接敲键盘输入任何关键词：

- **中英文混合匹配**：支持中文词汇、英文代码片段、网址 URL、文件名等无缝检索。
- **视觉高亮指示**：匹配到的关键词在中间列表的摘要卡片和右侧预览区会同步以醒目的黄色高亮标出，一目了然。
- **自定义别名优先检索（`⌘ R`）**：
  如果你经常使用某些高频长文本（如一条很长的 SQL 语句、一段模版邮件或公司发票抬头），可以选中该条目后按下 **`⌘ R`**（Command + R），为其设置一个简短的自定义别名（如 `开票信息`）。设置后，只要输入别名就能瞬间定位到该条目。

---

## 2. 拼音极速启动应用程序（App Launcher）

NookClip 不仅是一个剪贴板工具，还兼具轻量级应用启动器的能力。日常不需要频繁呼出 Spotlight 或 Raycast，在 NookClip 内部就能一步搞定。

### 怎么使用：

1. 按 `⌘ ⇧ V` 呼出面板。
2. 输入本地已安装应用的名称或**中文拼音首字母**：
   - 输入 `wx` → 自动匹配 **微信 (WeChat)**
   - 输入 `zd` → 自动匹配 **终端 (Terminal)**
   - 输入 `fs` → 自动匹配 **飞书 (Feishu)**
   - 输入 `code` → 自动匹配 **Visual Studio Code**
3. 列表首项会出现带有专属应用图标的启动卡片，直接按 **`⏎` (回车)** 即可瞬间唤醒该应用并切换至前台。
