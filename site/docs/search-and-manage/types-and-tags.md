# 类型分类与标签管理

除了按时间倒序翻阅和按关键词全文搜索，NookClip 还提供了强大的 **类型槽位** 与 **自定义标签系统**，帮助你把日常积累的大量片段整理得井井有条。

---

## 1. 8 大固定类型槽位

NookClip 的顶部筛选栏包含 8 个固定槽位，按业务属性分类且排列位置固定不变，不会因为内容数量增减而出现跳动：

1. **收藏（Star）**：加星标的重要内容（收藏内容永久保留，绝不会被条数上限淘汰）。
2. **图片（Image）**：截图、照片与图形文件。
3. **文本（Text）**：日常文本段落与排版内容。
4. **链接（Link）**：网址 URL（自动支持预览区直接生成二维码扫码打开）。
5. **代码（Code）**：代码片段与脚本，支持自动高亮。
6. **文件（File）**：从访达复制的文件对象（如文件已删除，会有醒目的失效警示）。
7. **色值（Color）**：十六进制颜色值（如 `#1677FF`），直接显示色块，一键复制 RGB/HEX。
8. **回收站（Trash）**：被删除的内容会暂存这里，随时可以恢复或彻底清空。

### 全键盘快速切换类型

- 按 **`⌘ ]`**（Command + 右中括号）：切换到下一个有内容的类型。
- 按 **`⌘ [`**（Command + 左中括号）：切换到上一个有内容的类型。
- **自动跳过空分类**：如果某个分类下没有任何记录，键盘切换时会自动跳过，避免停留在空白页。

---

## 2. 展开与收起筛选面板（`⌘ ↓`）

- 按下 **`⌘ ↓`**（Command + 下方向键），即可在搜索框下方展开完整的筛选面板（或收起面板）。
- 按下 **`⌘ F`**（Command + F），可以直接聚焦搜索框并自动展开该筛选面板。
- 面板展开后，你可以清晰看到每个分类下的条目数量统计，以及下方的标签流。

---

## 3. 自定义标签（Tags）

标签系统适合用来横向组织跨类型的内容，例如给一段代码和一个网址同时打上 `#项目A`。

### 如何给记录打标签：
1. 选中任意一条记录。
2. 按下快捷键 **`⌘ L`**（Command + L）。
3. 弹出标签编辑浮层，输入标签名称并敲回车即可添加（支持一条记录添加多个标签）。

### 标签与类型的叠加筛选：
在筛选面板的下方，会列出你创建过的所有标签流。
- 你可以单独点击某一个标签只看相关内容。
- 也可以**与上方类型槽位叠加**：例如先选中【链接】类型，再在下方点击 `#常用` 标签，瞬间筛选出所有标记为常用的网址。

### 退格键快速移除筛选（`⌫`）：
当搜索框聚焦且内容为空时，连续敲击退格键 **`⌫`**，系统会智能地**由内到外逐层移除过滤条件**：
1. 第一次按 `⌫`：先移除当前生效的自定义标签；
2. 第二次按 `⌫`：移除当前生效的类型分类，回到全量列表。
无需用鼠标去点关闭小叉，键盘流一气呵成。
