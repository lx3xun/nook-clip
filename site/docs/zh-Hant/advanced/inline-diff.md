# 兩筆記錄行內對比（⌘ D）

核對兩版設定、比較 AI 前後兩次生成的程式碼、確認合約條款到底改了哪幾個字——這類「只看差異」的工作，傳統做法是打開專門的對比軟體，再分別開兩個分頁把兩段內容貼進去，來回切屏、還得手動對齊行號。

**NookClip 直接把對比搬到歷史列表裡：按 `⌘ D`，或點多選底欄 / 預覽區頂欄 / 右鍵選單裡的「對比」，右側預覽區立刻變成紅綠標示的差異檢視，字詞級的改動也標得出來，還能逐塊挑選保留哪一版，一鍵複製合併後的結果。**

---

## 1. 怎麼觸發

除了按快捷鍵 **`⌘ D`**，你也可以直接點擊介面上的 3 處可見入口：**勾選 2 筆記錄時底部工具列的「對比」按鈕**、**右側預覽區頂欄「⋯ 更多」選單裡的「對比」**，或在**列表任意條目上點右鍵選擇「對比兩筆記錄」**。

| 你的操作 | NookClip 的反應 |
| :--- | :--- |
| 選中第 1 筆（或未選中）觸發對比 | 自動拿列表**最上面兩筆**記錄來對比：第 2 筆當「舊版」、第 1 筆當「新版」（列表按最近使用時間倒序，越靠上越新） |
| 單選列表下方的第 N 筆（N > 1）觸發對比 | 拿**你當前選中的這筆**當「舊版」，與列表**最上面最新那筆**（「新版」）對比 |
| 勾選 **2 筆**記錄後觸發對比 | 按列表裡的上下位置決定新舊：靠下的那筆是舊版，靠上的是新版 |
| 勾選了 **3 筆及以上**再按 `⌘ D` | 不會靜默挑兩筆，直接提示「一次只能對比 2 筆」 |

對比開始後，左側列表會自動把參與對比的這兩筆**同時標示**，右側標題列也標出「舊」和「新」，不會看錯邊。

### 對比中途想換一筆記錄即時比對

進入對比後**不用先退出重選**，可以直接在左側列表切換另一側記錄，右側差異會即時重新整理：

- **按 `↑` / `↓` 或直接點擊列表其他行**：固定當前帶圖釘標記的基準記錄（預設固定靠上的「新版」），即時把另一側換成你剛選中或點到的那一筆。
- **想換固定哪一側**：點擊右側頂欄的「舊」或「新」膠囊（或在左側列表點一下正在對比的某一筆），就能把圖釘切到那一側；也可以按住 **`⌘`（或 `⇧`）點擊**另一筆記錄，把剛看的這筆固定下來與新點的那筆對比。

### 想退出對比

- 再按一次 **`⌘ D`**，或
- 按 **`Esc`**（對比態優先於其他退出層級，一按就回到一般預覽），或
- 點擊右側對比頂欄右上角的 **`×`**，或左側底欄的 **「退出對比」**。

## 2. 差異是怎麼標出來的

對比結果分兩層給你看，既能一眼掃出哪幾行變了，也能看清那一行裡到底改了哪幾個字：

1. **行級底色**：刪掉的行鋪淡紅底並帶 `-` 號，新增的行鋪淡綠底並帶 `+` 號，沒變的行保持原樣。
2. **行內字詞級加深**：當某一行只是局部改動（比如把 `timeout: 30` 改成 `timeout: 60`，或把合約金額 `10000` 改成 `12000`），整行不會胡亂塗滿，而是只把 `30` 和 `60` 用更深的紅/綠底圈出來，刪掉的字還會加上**刪除線**，對色覺差異使用者也同樣清晰。

> 💡 **中英文與變數名都能精準切開**：英文單字、數字、`camelCase` 駝峰命名、`snake_case` 底線命名會按詞切開（例如 `maxRetryCount` → `maxRetryTotal` 只標 `Count` 和 `Total`）；中文、中日韓標點與 Emoji 則按字切分，不會把半個漢字劈開。

---

## 3. 三種檢視方式

在右側差異摘要列右端，可以隨時切換三種檢视方式：

- **行內（預設）**：刪掉的舊行與換上的新行緊挨在一起，一眼順著讀完整上下文，適合「只改了幾處」的場景。
- **左右**：左欄固定放舊版、右欄固定放新版，同一處改動左右水準對齊，適合「整段被改寫」的場景。
- **只看差異**：把連續超過一段的未改動內容折疊起來，密集檢視所有變更點。

---

## 4. 複製或貼上合併後的版本

底部操作列固定提供兩個出口：

- **`⌘ C` 複製合併版**：把對比生成的完整文字寫進系統剪貼簿；
- **`⏎` 貼上合併版**：直接貼進你剛才切換前的目標視窗並收起面板。

> 💡 如果對比的內容裡有敏感資訊（API 金鑰、密碼等），複製合併版同樣會走敏感保護：剪貼簿 30 秒後自動清除。

## 5. 快捷鍵一覽（對比態內）

| 快捷鍵 | 動作 |
| :--- | :--- |
| **`⌘ D`** | 開始對比 / 退出對比 |
| **`↑`** / **`↓`**（或點擊列表其他行） | 固定基準側不變，即時切換另一側記錄並重新整理差異（按 `⇧ ↑` / `⇧ ↓` 或 `⌘ 點擊` 則以當前游標行作為新基準） |
| **`⌥ ↑`** / **`⌥ ↓`** | 跳到上一處 / 下一處改動（右側會自動捲動到那一塊並描邊提示） |
| **`⌘ C`** | 複製合併版 |
| **`⏎`** | 貼上合併版 |
| **`Esc`** | 退出對比（把游標移回列表、繼續翻歷史） |

---

## 6. 邊界情況：什麼能對比、什麼不能

- **純圖片 / 無文字記錄**：如果兩筆裡有一筆是還沒做過 OCR 的純圖片，沒法直接比文字，介面會提示你先點「辨識文字（OCR）」提取出文字再比。
- **敏感憑證記錄**：如果其中一筆是加密保護的密碼或 API Key，預設會先擋一道，點 **「解鎖並對比」** 才會解密比對；一旦退出對比或收起面板，解密出的明文立即從記憶體清掉。
- **超大文字**：超過 20 萬字或 5,000 行的超長日誌會自動切到輕量行級模式，保證面板不卡頓。
