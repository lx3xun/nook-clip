# 順序貼上佇列（Paste Stack）

順序貼上佇列是 NookClip 最受歡迎的高階效率功能之一。

在日常辦公中，我們經常遇到這樣的場景：需要把網頁或表格裡的姓名、電話、信箱、地址 4 段內容，分別填入系統表單的 4 個輸入框中。傳統做法是：複製一項 → 切屏貼上一項 → 切屏再複製下一項……來回切換應用多次，極其繁瑣且容易貼錯。

**有了順序貼上佇列，你只需要一口氣把所有內容複製完，然後切到目標視窗按原生的 `⌘ V` 連擊即可逐筆貼上！**

---

## 三種啟動方式

### 方式一：從既有歷史中多選啟動（最常用）

如果你要貼上的內容已經在 NookClip 歷史記錄中了：

1. 按 `⌘ ⇧ V` 叫出主面板。
2. 按住 `Shift` 配合上下鍵，或者用滑鼠按住整段拖曳勾選你要用的那幾筆內容。
3. 按下快捷鍵 **`⌥ ⏎`**（Option + Return）。
4. 螢幕底部立刻升起一個小巧的懸浮佇列面板，順序貼上佇列啟動成功！

> 💡 **先進先出順序**：NookClip 會按照你**當初複製的先後時間順序**（最早複製的排在第一位）排列佇列，與主介面中「最新記錄排在最上」相反，完全符合你的直覺。

### 方式二：邊複製邊入佇列（全局錄製模式）

如果你準備從一篇長文章或網頁中提取多段散落的內容：

1. 在任意地方按下全局快捷鍵 **`⌃ ⌥ V`**（Control + Option + V）開啟錄製模式。
2. 螢幕底部出現空佇列面板。
3. 接下來，你只需在來源網頁或文件中正常選中文字按 **`⌘ C`**。每按一次，螢幕上就會有一張小卡片伴隨平滑動畫「飛入」佇列底部。
4. 複製完畢後，直接切換到目標視窗開始貼上，不需要手動關掉錄製。

### 方式三：複製表格或收件資訊自動拆解（連續填表）

當你複製一段 Excel 表格、多欄文字、鍵值對或收件人資訊（如「王小明 0912-345-678 台北市信義區…」）時：

1. 游標附近會自動浮現一枚 **「連續填表」** 輕量膠囊提示，顯示辨識出的類型與拆解項數。
2. 點擊膠囊上的 **「連續填表」** 按鈕（或直接按 **`⌥ ⏎`**），NookClip 會把整段文字按欄位拆成多筆並直接裝入順序貼上佇列。
3. 也可以在主面板裡單選這類結構化條目後按 **`⌥ ⏎`** 直接拆解入佇列（一般文字單選按 `⌥ ⏎` 仍為純文字貼上）。
4. 若不需要自動提示，可在 **「設定 → 記錄 → 連續填表」** 中關閉。

## 怎麼貼上與使用

佇列建立好之後，你甚至**不需要**再去碰 NookClip：

1. 切換到你的目標應用（如 Excel、Notion、程式碼編輯器或線上表單）。
2. 將游標定位在第一個輸入框，直接按系統原生的 **`⌘ V`**（Command + V）——第一筆內容立刻貼入！
3. 按 `Tab` 切換到下一個輸入框，再按一次 **`⌘ V`**——第二筆內容貼入！
4. 如此往復，直到所有條目全部貼完，佇列面板自動完成使命並收起。

### 佇列面板上的狀態指示與互動

- **進度指示**：面板右側明確顯示 `已貼 2 / 5` 進度。
- **當前待貼項**：行首帶 **`▶`** 綠色箭頭的條目就是當前剪貼簿裡的下一項。
- **已貼項標記**：已經貼出的條目會自動變為灰色並打上刪除線勾選，清楚知道貼到了哪裡。
- **插隊點按**：用滑鼠點某一行，可以僅改變焦點而不做貼上；也可以直接點某行右側的 **「貼上」** 按鈕立刻貼出那特定的一筆。
- **不搶焦點**：佇列面板完全不會奪走當前文字框的輸入焦點，打字和游標切換絲毫不受影響。
- **隨意拖動**：按住面板空白處可以把它拖到螢幕任意角落，軟體會記住你的位置偏好。

---

## 隨時退出與中斷

如果貼到一半不想繼續了：

- 在任何視窗中直接按 **`Esc`** 鍵，佇列面板立即收起退出。
- 或者再次按下 **`⌃ ⌥ V`** 即可主動關閉佇列。
- 也可以直接點擊佇列面板右上角的關閉按鈕。
