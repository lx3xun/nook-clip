# 手機互傳（Phone Drop）

想把手上 Mac 裡一段很長的文件、一張截圖或一個檔案傳到手機，過去得先傳給自己一則訊息、登入網路硬碟，或兩台裝置都裝上同一個 App。用 Android 手機、或沒有登入同一個帳號時，這條路徑常常乾脆走不通。

**手機互傳**把這件事變成「掃一下就完成」：在 Mac 上選取一筆記錄，點「手機互傳」，手機用系統相機掃一下 QR Code，就能在瀏覽器裡直接檢視並複製電腦上的長文字、下載原圖或檔案；手機上的文字和照片也能直接傳回 Mac 剪貼簿。**手機不用安裝任何 App，網頁自動適配繁中 / 簡中 / 英文，資料只在同一個區域網路內傳輸，不經過任何雲端伺服器。**

---

## 1. 怎麼觸發 / 它怎麼運作

1. 在 NookClip 主面板裡選取任意一筆記錄（文字、程式碼、圖片、檔案都可以）。
2. 點開預覽區頂欄右側的**「⋯ 更多」**選單，選擇**「手機互傳」**。
3. 彈出的視窗會顯示一個 QR Code，並附上「區域網路位址」和即時倒數。預設 **5 分鐘**有效。
4. 手機連到和電腦**同一個 Wi-Fi**，用系統相機掃一掃，就能在手機瀏覽器裡開啟這個頁面，直接開始收發。

> 如果選取的是一條網址，QR Code 預設會給出「連結 QR Code」，並提示你可以切換成「雙向互傳」模式：既能開啟這個網址，也能繼續往電腦回傳內容。

同時，電腦會在本機暫時啟動一個小服務、並產生一個**一次性隨機權杖**，只有掃到這個 QR Code 的裝置才能存取。**傳輸期間請保持此互傳介面開啟**——一旦關閉彈窗、切換面板或倒數結束，服務會立即停止，連線隨即中斷並釋放連接埠。

---

## 2. 手機端能做什麼

手機瀏覽器裡的頁面分成上下兩部分：上面看電腦送來的內容，下面把手機內容傳回電腦。

**下發（電腦 → 手機）**

| 內容類型 | 手機端操作 |
| :--- | :--- |
| 長文字 / 程式碼 | 完整檢視，單擊「複製」即複製到手機剪貼簿 |
| 圖片 | 檢視原圖，可長按或點「下載」儲存到手機相簿 |
| 檔案 | 點「下載」儲存到手機 |

**上行（手機 → 電腦）**

| 內容類型 | 手機端操作 |
| :--- | :--- |
| 文字 | 在頁面底部的輸入框裡輸入文字，點「傳送」，電腦剪貼簿立刻收到並存入歷史清單 |
| 圖片 / 檔案 | 從相簿選擇圖片，或點選擇檔案，選取後一鍵傳回電腦 |

電腦收到回傳內容時，會彈出一句輕提示「已收到來自行動裝置的剪貼內容」，並自動記入歷史，之後照著平時的習慣使用即可。

## 3. 安全邊界

- **只在同一個區域網路內**：電腦和手機必須連在同一個 Wi-Fi / 區域網路，跨網路無法存取。
- **一次性隨機權杖**：每次開啟都會產生新的隨機權杖，連結只在本次有效，別人拿到舊 QR Code 也打不開。
- **5 分鐘自動失效**：預設倒數結束，服務自動關閉；也可以隨時點「停止分享」立即結束。
- **關閉即釋放連接埠**：關閉彈窗或倒數結束時，暫時服務立即停止，連接埠隨之釋放，不做常駐監聽。
- **單次上傳 50MB 上限**：手機回傳的單一檔案或圖片不超過 50MB，避免大檔案佔滿記憶體。
- **不經過任何雲端伺服器**：所有資料傳輸都發生在你的電腦和手機之間，不落任何第三方伺服器，也不需要帳號登入。

## 4. 常見問題

**Q：手機掃碼後打不開頁面？**
先確認電腦和手機連的是同一個 Wi-Fi。如果電腦目前沒有區域網路連線，NookClip 會提示「請先連接 Wi-Fi 或區域網路」，連上後再點一次「手機互傳」即可。

**Q：關掉面板後還能掃碼嗎？**
不能。互傳介面下方會提示「傳輸期間請保持此介面開啟，關閉或切換將立即中斷連線」。一旦關閉彈窗、收起主面板或倒數結束，暫時服務會立刻停止、連接埠釋放，舊的 QR Code 和連結都會中斷失效。需要時重新點「手機互傳」產生新的 QR Code。

**Q：手機上傳後電腦沒反應？**
確認電腦上的互傳 QR Code 介面仍保持開啟（未關閉或切換），且手機和電腦在同一個網路下。上傳成功後電腦會提示「已收到來自行動裝置的剪貼內容」，並自動存入歷史清單。

**Q：手機需要安裝 App 嗎？**
不需要。手機開啟的是網頁，用系統相機掃碼即可，iOS 和 Android 都適用。
