# 螢幕置頂貼條（Pinned Note）

在寫程式碼、做表格、核對帳單或照著參考圖改設計稿時，我們經常需要對照某一段歷史複製過的文字、色碼或截圖。如果兩個視窗都最大化，就不得不反覆 `⌘ Tab` 來回切換。

**NookClip 的「螢幕置頂貼條」可以把任意一筆剪貼簿記錄直接「釘」在螢幕最上層，當作隨時可見的懸浮參考卡！**

---

## 1. 怎麼建立置頂貼條（`⌘ P`）

1. 按 `⌘ ⇧ V` 叫出 NookClip 主面板。
2. 選中你要參考的程式碼、純文字、圖片或色碼記錄。
3. 按下快捷鍵 **`⌘ P`**（Command + P）。
4. 剛才的內容立即變成一個半透明的小巧置頂貼條，始終固定在所有軟體的最上方。

> 💡 **原位替換機制**：如果你在 NookClip 裡對另一筆記錄再次按下 `⌘ P`，它會直接原位替換掉當前螢幕上的貼條，保證螢幕整潔，不會留下一堆雜亂的臨時小窗。

---

## 2. 貼條的實用能力

### 保持語法醒目顯示與富媒體形態
- **程式碼貼條**：釘住的程式碼保留彩色語法醒目顯示，字級適中，易於對照閱讀。
- **圖片貼條**：截圖或設計稿直接以無邊框畫布置頂展示，支援自由縮放視窗大小。
- **色碼貼條**：直觀展示顏色色塊和 HEX / RGB 色碼。

### 調節透明度與摺疊
- 按住 **`⌥`（Option）配合滑鼠滾輪**（或懸停拖動控制條滑桿），可在 `20% ~ 100%` 之間無段調節半透明度，即使蓋住底層視窗也能看清下方文字。
- 點擊控制條上的摺疊按鈕，可將貼條收起為單行標題列，需要時再展開。

### 滑鼠點擊穿透（鎖定）
當你需要邊看貼條邊在貼條下方的編輯器裡敲鍵盤或點擊滑鼠時，為了防止滑鼠誤觸貼條：

1. 點擊貼條右上角的 **小鎖圖示**，貼條將進入「滑鼠穿透模式」。
2. 此時貼條如同空氣，滑鼠的點擊和捲動動作會直接透過它，作用在它正下方的軟體上。
3. **如何恢復點擊**：按下全局快捷鍵 **`⌘ ⌥ P`**（Command + Option + P），或者點擊貼條角落解鎖圖示，即可退出穿透模式。

### 內聯編輯草稿
- 貼條不僅可以看，還能直接編輯。在貼條文字區域點一下，即可當作臨時草稿修改文字、補充要點。
- 修改完成後，點擊底部的儲存按鈕，可以直接作為一筆新記錄存回剪貼簿歷史中。

---

## 3. 怎麼關閉貼條

- 點擊貼條左上角或右上角的關閉按鈕 `✕`；
- 選中貼條時直接按鍵盤的 **`Esc`** 鍵即可關閉。
