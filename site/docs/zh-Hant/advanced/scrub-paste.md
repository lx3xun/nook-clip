# 語義脫敏貼上與還原（Scrub & Unscrub）

在使用 ChatGPT、Claude 等 AI 助手幫忙排查程式碼 Bug 或分析日誌時，我們經常需要把設定檔、環境變數（`.env`）或報錯日誌貼給 AI。

但這些內容裡往往夾雜著真實的 **API 金鑰、資料庫密碼、手機號碼、電子信箱、內網 IP 或銀行卡號**。手動一個個找出來刪掉既費時又容易漏，直接貼出去又有嚴重的資安外洩風險。

**NookClip 的「語義脫敏貼上」讓你只需按一下 `⌃ ⏎`，就能自動把所有敏感資訊替換成 AI 看得懂的安全佔位符；等 AI 改完程式碼發回來，再按 `⌃ ⇧ ⏎` 就能一鍵把真實金鑰原位填回！**

---

## 1. 怎麼使用語義脫敏貼上（`⌃ ⏎`）

當你複製了一段包含金鑰或隱私資訊的程式碼/日誌後：

1. 按 `⌘ ⇧ V` 叫出 NookClip，選中該筆記錄。
2. 按下快捷鍵 **`⌃ ⏎`**（Control + Return）。
3. NookClip 會在毫秒級內自動偵測其中的敏感資料，並把它們替換為具業務語義的可讀佔位符（例如 `<API_KEY_1>`、`<PASSWORD_1>`、`<EMAIL_1>`），然後再貼上到前台輸入框中。

### 為什麼叫做「語義」脫敏？

假設你的原始內容是：
```env
OPENAI_API_KEY={{OPENAI_KEY_f4e1dd07}}
BACKUP_KEY={{OPENAI_KEY_f4e1dd07}}
ADMIN_EMAIL={{EMAIL_c83dc5ef}}
```

按下 **`⌃ ⏎`** 貼給 AI 的內容會變成：
```env
OPENAI_API_KEY=<API_KEY_1>
BACKUP_KEY=<API_KEY_1>
ADMIN_EMAIL=<EMAIL_1>
```

- **保留上下文結構**：AI 依然能看懂這是一個 API Key 和一個 Email，不會破壞程式碼語法和邏輯。
- **相同值共享編號**：同一段內容中如果同一個 Key 出現了兩次，它們都會被替換成 `<API_KEY_1>`，AI 能夠理解這兩個變數引用的是同一個值。

### 支援自動脫敏的 19 類資訊：
- **開發憑證**：OpenAI / Anthropic / AWS / GitHub Token、通用 API Key、Bearer Token、JWT、PEM 私鑰、資料庫連線字串（Postgres / MySQL / Mongo / Redis）、密碼欄位。
- **個人隱私**：手機號碼、身分證號、銀行卡號、IBAN 國際帳號、電子信箱。
- **環境資訊**：IPv4 / IPv6 位址、內網主機名、本機使用者家目錄路徑（如 `/Users/yourname/...` 自動替換為 `/Users/<USER_1>/...`）。

> 🛡️ **零誤傷演算法**：內建嚴格的校驗和檢查——銀行卡經過 **Luhn** 校驗、身分證經過 **ISO 7064** 校驗；像 `127.0.0.1` 本機迴路位址、`/Users/Shared` 等日常開發文字絕不會被誤當作敏感資訊。
> 同時支援在「設定 → 隱私」中開啟**離線人名與地址辨識**（呼叫 macOS 本機語言模型，全程不連網），以及新增**自訂脫敏規則**（支援關鍵字或正規表示式 + 自訂佔位符標籤）。

---

## 2. 怎麼把 AI 的回覆一鍵還原（`⌃ ⇧ ⏎`）

當 AI 幫你重構完程式碼，回覆裡帶著 `<API_KEY_1>` 和 `<EMAIL_1>` 時：

1. 直接複製 AI 回覆的程式碼。
2. 叫出 NookClip 選中剛才複製的內容（預覽區會貼心提示：`偵測到 N 個脫敏佔位符`）。
3. 按下快捷鍵 **`⌃ ⇧ ⏎`**（Control + Shift + Return）。
4. NookClip 會自動把程式碼裡的所有 `<API_KEY_1>` 原位替換回你真實的金鑰，並直接貼上到你的開發工具中！

---

## 3. 預覽區主動安全提醒

為了防止你在不經意間直接按 `⏎` 把真實密碼貼出去：

- 當你選中的記錄中包含任何可脫敏的敏感資訊時，右側預覽窗格頂部會自動浮現一條琥珀色的輕量提醒橫幅：
  > **「偵測到 2 處敏感資訊（API Key、信箱） · 按 ⌃⏎ 脫敏貼上」**
- **絕不打擾**：它不會彈出視窗阻斷你的操作，如果你確實需要貼上真實值，直接按一般 Return `⏎` 依然可以原樣貼出。
- **開關自由**：可以在「設定 → 隱私」中根據個人習慣關閉此提醒。

---

## 4. 極致的安全性設計

- **映射關係僅駐留記憶體**：佔位符與真實密碼的映射表**僅保存在本機執行記憶體中**，絕對不會寫入資料庫、不會寫入磁碟檔案、更不會上傳網路。
- **自動銷毀**：系統閒置 30 分鐘後，記憶體中的映射表會自動銷毀。
- **隨時清空**：前往「設定 → 隱私」，可以隨時查看當前記憶體映射數並點擊一鍵清空。
