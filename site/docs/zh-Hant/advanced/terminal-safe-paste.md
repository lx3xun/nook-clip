# 終端機安全貼上護欄（Terminal Safe-Paste）

從網頁教程、AI 回答或運維文件複製指令貼進終端機時，最怕兩件事：

1. **多行文字自帶換行符 `\n`**——剛貼進去還沒來得及改參數，終端機已經當成按了 Return 逐行跑起來了；
2. **指令裡夾著高風險操作**——比如 `rm -rf`、`sudo`、`curl ... | sh`、`git push --force`、`DROP TABLE`，甚或網頁暗藏的零寬字元與 ANSI 跳脫序列。

**NookClip 的「終端機安全貼上護欄」會在貼向終端機的那一瞬間幫你踩下煞車：把將要執行的指令和命中的風險原因攤開給你看，推薦改成「串成單行、只貼不執行」的安全貼上方式。**

---

## 1. 什麼時候會觸發？

只有**同時滿足**以下兩個條件時，護欄才會彈出，平時在編輯器、聊天軟體、瀏覽器裡貼程式碼**完全無感、零打擾**：

| 條件 | 具體規則 |
| :--- | :--- |
| **1. 當前前台視窗是終端機** | 內建覆蓋 **Terminal.app、iTerm2、Warp、Alacritty、kitty、Ghostty、WezTerm、Hyper、Tabby** 等 9 款主流終端機；也可在設定裡加入自訂終端機，或在 **VS Code / Cursor / Zed / JetBrains** 等 IDE 內建終端機中啟用 |
| **2. 剪貼內容命中風險規則** | 包含 **多行指令（`≥ 2` 行）**、**尾隨換行符**，或命中 **10 類高風險指令 / 隱藏字元** 之一 |

### 內建偵測的 10 類高風險特徵

- **多行與尾隨換行**：多行指令、末尾帶 `\n` / `\r`（貼進終端機會立刻觸發執行）
- **權限提升與破壞性刪除**：`sudo` / `su` / `doas`、`rm -rf`（或 `rm -fr` / `--no-preserve-root`）
- **遠端腳本直跑**：`curl ... | sh`、`wget ... | bash` 等下載管道執行
- **磁碟與權限高危操作**：`dd if=... of=/dev/...`、`mkfs`、`diskutil eraseDisk`、`chmod -R 777`、`chown -R`
- **服務與進程終止**：`kill -9`、`killall`、`pkill`、`systemctl stop/disable`、`launchctl unload`
- **Git 歷史覆蓋**：`git reset --hard`、`git push --force` / `-f`、`git clean -fd`
- **資料庫刪表刪庫**：`DROP DATABASE`、`DROP TABLE`、`TRUNCATE TABLE`、無 `WHERE` 的 `DELETE FROM`
- **系統網路與認證變更**：`iptables -F`、`pfctl -F`、`ufw disable`、寫入 `~/.ssh/authorized_keys`
- **隱藏字元攻擊**：零寬字元 / 雙向文字控制符（Trojan Source）、ANSI 控制序列、Base64 解碼管道執行

> 💡 **預覽區提前預警**：即使還沒按貼上，只要在主面板選中含上述高風險特徵的條目，右側預覽區頂部也會顯示紅色提示條，列出命中的具體原因（如 `rm -rf 強制遞迴刪除`、`curl|sh 遠端腳本直接執行`）。

---

## 2. 攔截彈窗的三個選項

觸發護欄後，會彈出確認框並列出本次命中的風險原因與完整指令預覽：

### 安全貼上（推薦）

把多行指令用 ` && ` **串成一行**，貼上後停在終端機輸入行，**不會自動按 Return 執行**。你可以先掃一眼指令、用方向鍵修改局部，或按 `⌃C` 放棄，確認無誤後再親自按 Return 執行。

### 原樣貼上

保留原始的多行格式與換行符直接貼入（適合貼進 `vim` / `nano` 編輯器、多行 heredoc 或你已完全確認安全的腳本）。

### 取消（`Esc`）

放棄本次貼上，不向終端機發送任何按鍵。

---

## 3. 安全邊界：什麼情況不會攔？

- **單行普通安全指令**（如 `ls -la`、`git status`、`brew update`，且末尾沒有換行符）：直接放行秒貼，絕不彈窗。
- **註解行與空行**：計算有效指令行數時會自動跳過 `#` 開頭的註解行和空行；連接行尾反斜線 `\` 的折行指令也會先合併再判斷。
- **非終端機應用**：在備忘錄、微信、瀏覽器、Word 裡貼任何指令都不會觸發終端機護欄。

---

## 4. 如何關閉或自訂終端機列表？

前往 **「設定 → 貼上」** 分頁的 **「終端機安全貼上」** 區塊：

1. **終端機安全貼上護欄**：總開關（預設開啟）。
2. **在編輯器內建終端機中也啟用**：開啟後，當 VS Code、Cursor、Windsurf、Zed 或 Xcode / JetBrains 系列處於前台且貼上內容命中**高風險指令**時，同樣會彈出確認框（普通多行程式碼在編輯器裡正常編寫不會誤攔）。
3. **自訂終端機應用**：如果你使用小眾終端機，可點擊「新增終端機應用…」直接從 `/Applications` 選入，或輸入其 Bundle ID。
