# 基礎使用

NookClip 的設計理念是 **「零干擾、全鍵盤、呼之即來」**。你無需改變原有的複製習慣，也不用頻繁動用滑鼠。

---

## 1. 叫出與收起主面板

- **叫出主面板**：在任意應用中按下全局快捷鍵 **`⌘ ⇧ V`**（Command + Shift + V）。
- **滑鼠叫出**：點擊螢幕右上角選單列的 NookClip 圖示。
- **自動隱藏**：在面板外任意位置點一下滑鼠，或者按 **`Esc`** 鍵，面板會自動退出並隱藏，不會殘留搶佔螢幕。

---

## 2. 瀏覽與預覽記錄

面板採用清晰的 **「左列表 · 右預覽」** 雙欄結構：

- **上下切換**：使用鍵盤 **`↑` / `↓`** 方向鍵在歷史記錄中移動。
- **即時預覽**：選中左側任意條目時，右側預覽窗格會即時展示完整內容：
  - **純文字**：完整段落、字數與行數統計。
  - **程式碼**：自動辨識語言並提供彩色語法醒目顯示。
  - **圖片**：顯示高畫質縮圖、解析度尺寸與檔案大小。
  - **色碼**：當複製 `#1677FF` 或 `rgb(...)` 時，預覽區直接渲染對應色塊。
  - **檔案與連結**：展示檔案路徑預覽或網址預覽卡片（支援生成 QR Code 手機掃碼打開）。

---

## 3. 直接打字即搜尋（無需點搜尋框）

叫出面板後，**你不需要先用滑鼠去點搜尋框，也不需要先按 `⌘ F`**：

- 直接敲擊鍵盤上的字母或文字，輸入內容就會自動進入頂部搜尋框。
- 列表會在幾毫秒內過濾出包含該關鍵字的歷史記錄，並在列表中醒目顯示匹配文字。

---

## 4. 四種基礎貼上操作

找到想要的記錄後，你可以根據場景選擇不同的貼上方式：

| 按鍵操作 | 行為效果 | 適用場景 |
| :--- | :--- | :--- |
| **`⏎` (Return)** | **直接貼上**：面板立刻收起，自動將內容貼入當前輸入框 | 最常用的日常貼上 |
| **`⌥ ⏎` (Option + Return)** | **純文字貼上 / 順序貼上佇列**：單選一般文字時自動剝離富文本格式；多選或單選表格/收件資訊時啟動順序貼上佇列 | 從網頁複製程式碼或帶格式文字到編輯器，或連續填表 |
| **`⌘ ⏎` (Command + Return)** | **貼上並保持面板開啟**：貼出內容但面板不收起 | 連續在兩個應用間比對資料，或者在同一表單連續填多項 |
| **`⌘ C`** | **重新複製**：將選中項裝入系統剪貼簿，但不做貼上動作 | 僅更新剪貼簿內容，稍後手動貼上 |

> 💡 **反白複製**：除了按 `⌘ C` 複製整筆記錄，你也可以用滑鼠在右側預覽窗格裡選中特定的一小段文字，然後按 `⌘ C` 提取局部內容。

---

## 5. 分層退出（Esc 機制）

為了防止使用者誤觸退出按鍵遺失剛剛輸入的搜尋詞或篩選條件，NookClip 的 **`Esc`** 鍵採用了智慧的**分層返回機制**：

1. 開啟了「重新命名別名」或「標籤編輯」浮層時，按 `Esc` 先關閉浮層；
2. 展開了搜尋框下方的篩選面板時，按 `Esc` 收起篩選面板；
3. 處於兩筆記錄對比檢視（`⌘ D`）時，按 `Esc` 退出對比；
4. 處於批次多選狀態時，按 `Esc` 退出多選；
5. 有搜尋詞、標籤篩選、類型篩選或時間分組條件時，按 `Esc` 逐層清空復位；
6. 以上狀態均已復位時，按 `Esc` 收起主面板。
