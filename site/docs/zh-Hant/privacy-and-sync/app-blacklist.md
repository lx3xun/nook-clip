# 應用黑名單與密碼管理器自動排除

有些軟體裡的複製內容，我們永遠不希望它被記錄到剪貼簿歷史中（例如你在 1Password 裡點擊「複製密碼」，或者在某個涉及機密的內部辦公軟體裡操作）。

NookClip 提供了 **「內建自動排除」** 與 **「自訂應用黑名單」** 雙重保護。

---

## 1. 密碼管理器與隱私標準自動排除

無需任何手動設定，NookClip 預設遵循 macOS 剪貼簿隱私標準（如 `org.nspasteboard.ConcealedType` 與 `TransientType`），能夠自動略過主流密碼管理器生成的臨時密碼複製動作：

- **1Password**
- **Bitwarden**
- **KeePassXC / MacPass**
- **Enpass / Dashlane**
- **macOS 系統「密碼（Passwords）」與「鑰匙圈存取」**

當你從這些軟體中複製帳號密碼時，系統剪貼簿依然可以正常貼上，但 NookClip 會自動裝作「沒看見」，絕不留存任何歷史痕跡。

---

## 2. 如何新增自訂排除應用（黑名單）

你可以把 Mac 上的任意應用程式加入到排除列表中：

1. 點擊螢幕右上角選單列的 NookClip 圖示，選擇 **「設定」**（或按快捷鍵 `⌘ ,`）。
2. 在設定視窗頂部切換到 **「隱私」**（排除應用）分頁。
3. 點擊下方的 **`[+]`** 按鈕，系統會彈出應用程式選擇面板。
4. 從列表中勾選或從 Finder 中選定你要排除的軟體（例如 `1Password.app`），點擊新增。
5. 列表中的應用即刻生效，以後從該應用複製的內容將永久免於被記錄。

> 💡 **隨時移除**：如果日後需要恢復記錄某個應用，只需在列表中選中它並點擊 `[-]` 移除即可。
