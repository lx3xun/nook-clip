# 貼完即焚與剪貼簿自動擦除

收到驗證碼簡訊時，往往整條都是「【XX銀行】您的驗證碼是 482910，5 分鐘內有效，請勿洩露」——複製後貼進網頁還得手動刪掉前後綴；而密碼、API Key 複製或貼上完之後，明文還會一直留在系統剪貼簿裡，切到任何軟體誤按一次 `⌘ V` 就會當眾貼出來。

**NookClip 把這兩件事合成了一套無感的保護閉環：複製驗證碼簡訊時自動提純成純數字碼，貼上驗證碼或敏感憑證後自動清空系統剪貼簿（就算複製後沒去貼，超時也會自動擦除）。**

---

## 1. 它怎麼運作：觸發條件與操作方式

| 功能 | 觸發條件 | 幫你做什麼 | 怎麼操作 / 干預 |
| :--- | :--- | :--- | :--- |
| **驗證碼自動提純** | 複製的單行文字同時包含「驗證碼 / 校驗碼 / 動態碼 / OTP / verification code」等提示詞與 `4–8` 位數字或字母碼 | 自動把系統剪貼簿替換為提取出的純驗證碼（如 `482910`），列表與預覽區顯示「驗證碼 482910」膠囊，右上角彈出小橫幅 | 直接在目標輸入框按 `⌘ V` 即可貼出純驗證碼；若這次需要貼完整簡訊原文，點橫幅上的 **「恢復原文」** 即可 |
| **貼完即焚（貼後即清）** | 驗證碼條目，或被辨識為敏感的密碼 / API Key 條目，在完成一次貼上後 | 等目標應用讀取完剪貼簿（約 `0.3 秒`）後，自動清空系統剪貼簿；若開啟了「同時銷毀歷史記錄」，還會把該筆記錄從 NookClip 歷史與資料庫中徹底移除 | 全自動執行，無需額外按鍵 |
| **超時自動擦除** | 複製了驗證碼或敏感憑證，但遲遲沒有貼上 | 預覽區頂部顯示即時倒數計時（如 `將在 28s 後從系統剪貼簿擦除`），到點自動清空系統剪貼簿 | 倒數期間可隨時點預覽區頂部的 **「保留此筆」** 豁免本次擦除，或點 **「立即焚毀」** 馬上清空 |

---

## 2. 核心設計細節

- **自動提純少一步手刪**：直接把驗證碼簡訊替換為純碼，`⌘ V` 一次到位。
- **貼上後延遲 0.3 秒清空**：既留給目標應用讀取剪貼簿的時間，又把明文暴露視窗壓到最短。
- **歷史銷毀預設關閉**：徹底刪除不可逆且繞過垃圾桶，預設交由使用者在設定中主動開啟。
- **選「不限制」時零常駐監聽**：無需自動擦除時不掛載鍵盤監聽，省電且零打擾。

## 3. 安全邊界：什麼情況絕不誤傷？

為了防止把日常正常文字當成驗證碼或誤清你剛複製的新內容，NookClip 設了多道嚴格邊界：

1. **沒有提示詞的純數字絕不當驗證碼**：單獨複製 `123456`、電話號碼、訂單號、金額、日期（`2026-04-20`）、時間（`12:30`）、版本號（`v1.2.3`）或網址時，沒有驗證碼關鍵字，**絕不會觸發提純或自動擦除**。
2. **多行文字、程式碼與連結不提純**：即使程式碼註解或長文裡提到了「驗證碼」三個字，只要超過 2 行、超過 240 字元或屬於程式碼 / URL / 檔案 / 圖片，一律原樣保留。
3. **複製了新內容絕不誤清**：倒數計時或 0.3 秒等待期間，如果你又複製了別的內容，NookClip 會比對系統剪貼簿序號（`changeCount`），發現剪貼簿已經換了新內容就立即取消擦除，**絕不會把你剛複製的新文字清掉**。
4. **收藏與置頂貼條豁免銷毀**：如果你給某條 API Key 點了收藏（`⌘ S`）或釘成了螢幕置頂貼條（`⌘ P`），即使開啟了「同時銷毀歷史記錄」，它也只會清空系統剪貼簿，不會刪掉你的收藏或貼條。
5. **無輔助使用權限時優雅降級**：如果尚未授予「輔助使用」權限，NookClip 不會彈窗索權，而是自動退化為純倒數計時擦除模式。

## 4. 如何關閉或自訂？

前往 **「設定 → 隱私」** 分頁的 **「貼完即焚与剪貼簿擦除」** 區塊，可獨立調節每一項：

| 設定項 | 預設值 | 可選範圍與說明 |
| :--- | :--- | :--- |
| **驗證碼自動提純** | 開啟 | 關閉後不再自動把驗證碼簡訊替換為純碼 |
| **驗證碼自動擦除** | **貼上後或 60 秒** | 可選：不限制 / 僅倒數計時（30秒、60秒、2分鐘、5分鐘）/ **貼上後或 30 秒** / **貼上後或 60 秒** |
| **敏感憑證自動擦除** | **30 秒後** | 可選：不限制 / 30秒後 / 60秒後 / 2分鐘後 / 5分鐘後 / 貼上後或 30 秒 / 貼上後或 60 秒 |
| **擦除時同時從歷史記錄銷毀** | 關閉 | 開啟後，觸發自動擦除時不僅清空系統剪貼簿，還會將該條目從 NookClip 歷史中永久刪除（不進垃圾桶） |
