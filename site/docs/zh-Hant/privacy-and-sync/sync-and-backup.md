# iCloud 跨裝置同步與備份匯出

NookClip 堅持「100% 無第三方伺服器」的架構原則。你的所有資料都完全掌控在你自己手中，同時支援在你的多台 Mac 之間安全同步，以及隨時匯出開放格式的備份檔案。

---

## 1. 原生個人 iCloud Drive 同步

如果你同時擁有一台辦公 MacBook 和一台家用的 Mac Studio / iMac，可以開啟 iCloud 同步：

- **無第三方伺服器**：NookClip 沒有搭建任何雲端儲存服務，所有同步完全走你裝置自帶的 Apple 官方 **iCloud Drive** 通道；
- **端到端原生通道**：資料僅在登入了你同一個 Apple ID 的受信任裝置之間流轉，任何外部第三方（包括軟體作者）都無法觸碰或截獲；
- **敏感資料預設隔離**：標記為敏感的記錄（密碼、Token、私鑰等）預設不參與雲端同步；進階使用者可開啟自訂口令的**端到端加密（E2EE）**，並按需選擇是否將敏感記錄加密同步至其他 Mac；
- **可選開啟**：預設關閉，可在「設定 → 同步」中隨時開啟。

---

## 2. 資料備份匯出與遷移（JSON / Markdown）

NookClip 絕不綁架使用者資料。你可以隨時將歷史記錄匯出為通用的標準檔案，用於離線備份、換機遷移或匯入到筆記軟體（如 Obsidian、Notion）中：

### 支援的匯出格式：
1. **標準 JSON 格式（完整備份與還原）**：
   保留完整的結構化欄位（內容、時間戳記、來源應用、收藏狀態、自訂標籤、別名等），可用於在新電腦上一鍵無損匯入恢復。
2. **Markdown 格式（筆記歸檔）**：
   排版整潔的可讀文件格式，適合將近期收集的資料一鍵歸檔到你的知識庫中。

### 匯出時的隱私保護選項：
在匯出時，你可以自由決定如何處理敏感記錄：
- **直接跳過敏感記錄**（不匯出任何密碼項）；
- **遮碼匯出**（將敏感內容打碼後匯出，防止備份檔案意外外流導致洩密）。

---

## 3. 自動清理與儲存空間上限

為了防止長時間使用後圖片和歷史記錄佔用過多硬碟空間，你可以在「設定 → 儲存」中自訂保留策略：

- **保留筆數上限**：如保留最近 500 筆 / 2,000 筆 / 10,000 筆；
- **保留天數上限**：自動清理超過 7 天 / 30 天 / 90 天的舊記錄；
- **圖片磁碟配額**：限制歷史圖片快取的最大磁碟佔用；
- **收藏豁免保護**：所有加了星號 **「收藏（`⌘ S`）」** 的重要記錄，永遠不會被自動清理規則淘汰。
