# 常見問題排查（FAQ）

這裡整理了安裝和日常使用 NookClip 時最常遇到的問題與解決方法。

---

### Q1：在面板裡按了 Return `⏎`，為什麼沒有自動貼上到當前視窗，而只是複製到了剪貼簿？

**原因**：macOS 的「輔助使用（Accessibility）」權限尚未授予，或者在軟體更新版本後權限快取失效了。

**解決方法**：
1. 打開 **「系統設定 → 隱私權與安全性 → 輔助使用」**。
2. 檢查列表中是否有 **NookClip** 且開關處於開啟狀態。
3. **如果你剛更新過 NookClip 版本（覆蓋安裝）**，即使開關顯示為開啟，macOS 有時也會因為簽名變動而靜默攔截。此時請：
   - 在輔助使用列表中選中 `NookClip`，點擊底部的 **`[-]`（減號）** 將其徹底移除；
   - 再點擊 **`[+]`（加號）**，重新從「應用程式」檔案夾把 `NookClip.app` 加進來並打開開關，即可立即恢復正常自動貼上。

---

### Q2：首次打開提示「無法驗證開發者」或「NookClip 已損毀，無法打開」？

**原因**：這是 macOS Gatekeeper 對未購買 Apple $99/年商業簽名證書的開源軟體的預設攔截提示，並非檔案真的損壞。

**解決方法**：
打開「終端機（Terminal）」，執行以下指令即可清除下載隔離標記並正常打開：
```bash
xattr -cr /Applications/NookClip.app
```

---

### Q3：按 `⌘ ⇧ V` 叫不出主面板？

**原因**：可能與你電腦上安裝的其他軟體（如其他剪貼簿工具、輸入法、截圖工具或 IDE 快捷鍵）發生了全局快捷鍵衝突。

**解決方法**：
1. 點擊螢幕右上角選單列的 NookClip 圖示，選擇「設定」。
2. 在「貼上」分頁中，重新錄製一個未被佔用的快捷鍵組合（例如 `⌥ 空白鍵` 或 `⌃ ⌥ V`）。

---

### Q4：為什麼我在 1Password 或系統密碼裡複製的密碼，沒有出現在 NookClip 中？

**原因**：這是 NookClip 的**隱私保護機制**。為了防止核心主密碼洩漏，NookClip 預設自動識別並忽略來自 1Password、Bitwarden、KeePassXC 等密碼管理器的複製行為。詳見 [應用黑名單與排除](./../privacy-and-sync/app-blacklist.md)。

---

### Q5：語義脫敏貼上（`⌃ ⏎`）生成的 `<API_KEY_1>` 映射表保存在哪裡？安全嗎？

**答**：**100% 僅保存在執行期記憶體（RAM）中**。
映射關係絕不會寫入硬碟資料庫，也不會上傳網路。當電腦閒置超過 30 分鐘或退出軟體時，記憶體映射會自動徹底銷毀。你也可以隨時在「設定 → 隱私」中手動一鍵清空。

---

### Q6：螢幕置頂貼條（`⌘ P`）開啟了「滑鼠點擊穿透」後，怎麼點不到它也關不掉了？

**原因**：開啟穿透模式後，為了讓你順暢操作底層視窗，貼條會忽略所有滑鼠點擊事件。

**解決方法**：
- 按下全局快捷鍵 **`⌘ ⌥ P`**（Command + Option + P），即可立刻恢復貼條的滑鼠互動。

---

### Q7：解除安裝或重新安裝軟體後，歷史資料還會保留嗎？

- **資料儲存位置**：NookClip 的本機資料庫預設保存在使用者目錄的 `~/Library/Application Support/com.lx3xun.nookclip/` 下。
- 如果僅僅將應用程式拖入垃圾桶重新下載，歷史資料會安全保留。
- 建議定期在「設定 → 資料管理」中使用匯出功能備份重要的條目。詳見 [iCloud 同步與備份匯出](../privacy-and-sync/sync-and-backup.md)。
