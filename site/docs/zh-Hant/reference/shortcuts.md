# 完整快捷鍵速查表

NookClip 為全鍵盤工作流進行了深度最佳化，幾乎所有操作都無需離開鍵盤。

---

## 1. 全局快捷鍵（在任意應用中生效）

| 快捷鍵 | 功能說明 | 備註 |
| :--- | :--- | :--- |
| **`⌘ ⇧ V`** | 全局叫出 / 隱藏主面板 | 可在「設定 → 貼上」中自由自訂錄製按鍵 |
| **`⌃ ⌥ V`** | 啟動 / 結束順序貼上佇列錄製 | 開啟後可一邊複製一邊存佇列，再次按下結束 |
| **`⌘ ⌥ P`** | 恢復螢幕置頂貼條的滑鼠點擊 | 退出貼條的「滑鼠點擊穿透鎖定」模式 |

---

## 2. 主面板：導覽與選擇

| 快捷鍵 / 操作 | 功能說明 | 備註 |
| :--- | :--- | :--- |
| **`↑` / `↓`** | 上下移動選中項 | 長按可流暢連續捲動 |
| **`⇧ ↑` / `⇧ ↓`** | 向上 / 向下連續多選條目 | 進入批次操作模式 |
| **滑鼠上下拖動** | 整段框選條目 | 按住 Shift 拖動可追加勾選，拖到邊緣自動捲動 |
| **`⌘ + 滑鼠點擊`** | 點選或取消選中單個條目 | 適合多選不連續的記錄 |
| **`⌘ T`** | 循環跳轉到下一個時間分組 | 例如在「今天」、「昨天」、「更早」之間快速跳轉 |
| **`⌥ ↑` / `⌥ ↓`** | 對比態內跳到上一處 / 下一處改動 | 僅在按 `⌘ D` 進入的對比檢視內生效，右側自動捲動到該塊並描邊 |

---

## 3. 主面板：貼上與提取

| 快捷鍵 | 功能說明 | 備註 |
| :--- | :--- | :--- |
| **`⏎` (Return)** | 貼上並收起面板 | 最常用的貼上；多選態下為批次合併貼上；輸入應用名時為啟動應用 |
| **`⌥ ⏎`** | 純文字貼上 / 連續填表 | 單選一般文字時剔除富文本格式；**多選狀態下或單選表格/收件資訊時啟動順序貼上佇列** |
| **`⌃ ⏎`** | 語義脫敏貼上 | 將 API 金鑰、密碼等敏感資訊替換為可讀佔位符再貼上 |
| **`⌃ ⇧ ⏎`** | 還原真實值貼上 | 將剪貼簿中的佔位符原位替換回真實密碼後再貼上 |
| **`⌘ ⏎`** | 貼上且保持面板開啟 | 貼出選中的內容，但主面板不關閉，適合連續填表與比對 |
| **`⌘ C`** | 重新複製到系統剪貼簿 | 僅更新剪貼簿內容，不執行前台貼上動作 |
| **`⌘ D`** | 對比兩筆記錄 / 退出對比 | 也可點預覽頂欄、勾選 2 筆時的底部工具列或右鍵選單觸發；對比中按 `↑↓` 或點選列表可即時換筆 |
| **`⌘ C`（對比態內）** | 複製合併後的版本 | 按你逐塊選擇的「保留新/舊/都留」拼出完整文字再寫入剪貼簿 |
| **`⏎`（對比態內）** | 貼上合併後的版本 | 直接貼進切換前的目標視窗並收起面板，與多選態的「合併貼上」不是同一動作 |

## 4. 主面板：整理、編輯與管理

| 快捷鍵 | 功能說明 | 備註 |
| :--- | :--- | :--- |
| **`⌘ P`** | 將選中項釘成螢幕置頂貼條 | 懸浮置頂在所有軟體最上層，再次按自動原位替換 |
| **`⌘ S`** | 收藏 / 取消收藏選中項 | 收藏的條目永久保留，免於歷史筆數淘汰 |
| **`⌘ R`** | 設定 / 修改自訂別名 | 留空按 Return 可清除別名，設定後可透過別名快速搜尋 |
| **`⌘ L`** | 為選中項編輯或新增標籤 | 彈出標籤編輯浮層 |
| **`⌘ ⌫`** | 刪除當前選中項或多選項 | 10 秒內按 `⌘ Z` 可復原恢復，之後轉入垃圾桶 |
| **`⌘ Z`** | 復原最近一次刪除 | 10 秒倒數計時內按下立即原位恢復 |

---

## 5. 主面板：搜尋、篩選與分層返回

| 快捷鍵 | 功能說明 | 備註 |
| :--- | :--- | :--- |
| **直接敲鍵盤** | 打字即時搜尋 | 叫出後無需任何切換，直接按鍵即可搜尋 |
| **`⌘ F`** | 聚焦搜尋框並展開篩選面板 | 自動展開類型網格與標籤流 |
| **`⌘ ↓`** | 展開 / 收起篩選面板 | 在緊湊列表與分類篩選面板間切換 |
| **`⌘ ]`** | 切換到下一個有內容的分類 | 自動跳過無記錄的空分類槽位 |
| **`⌘ [`** | 切換到上一個有內容的分類 | 自動跳過無記錄的空分類槽位 |
| **`⌫` (退格鍵)** | 逐層移除篩選條件 | 搜尋框為空時，依序移除「標籤 → 類型分類」 |
| **`Esc`** | 智能分層退出 | 依序：關閉浮層 → 收起篩選面板 → **退出對比檢視** → 退出多選 → 清空搜尋詞 → 移除篩選 → 收起主面板 |
| **`⌘ ,`** | 打開設定視窗 | 管理通用、貼上、隱私、同步等配置 |
