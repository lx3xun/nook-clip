# 批次操作與復原刪除

當你需要同時清理十幾筆無用記錄，或者把好幾段零散的筆記合併成一段發出去時，NookClip 提供了順滑的**多選批次操作**與**防誤刪復原機制**。

---

## 1. 怎麼進入批次多選模式

你可以用鍵盤或滑鼠任意一種習慣的方式進行多選：

### 鍵盤多選
- **`⇧ ↑` / `⇧ ↓`（Shift + 方向鍵）**：從當前焦點開始，連續向上或向下選定多個條目。
- **退出多選**：按一下 **`Esc`** 鍵即可瞬間取消選定，恢復單選狀態。

### 滑鼠拖曳框選（Drag Selection）
- 在列表任意區域**按住滑鼠左鍵並上下拖動**，可以直接劃過並勾選整段條目。
- 按住 `Shift` 拖動可以在既有勾選基礎上追加選擇。
- **邊緣自動捲動**：當拖動滑鼠觸碰到列表的上方或下方邊緣時，列表會自動平滑加速捲動，方便一次性多選跨屏的長列表。
- **`⌘ + 滑鼠點擊`**：精準點選某幾個不連續的條目。

---

## 2. 批次處理的高頻操作

當選中多筆記錄後，底部會浮現批次操作工具列，支援以下快捷動作：

- **批次合併貼上（`⏎` Return）**：
  將所有勾選的文字條目按順序用換行符拼接成一整段，一次性貼入目標視窗。
- **啟動順序貼上佇列（`⌥ ⏎`）**：
  按下 Option + Return，將勾選的條目排入順序貼上佇列，隨後逐筆貼出（詳見 [順序貼上佇列指南](../advanced/paste-stack.md)）。
- **對比兩筆記錄（`⌘ D`）**：
  當恰好勾選 **2 筆**記錄時，底部工具列會出現「對比」按鈕（或直接按 `⌘ D`），右側即刻展示行級與字詞級紅綠差異（詳見 [兩筆記錄行內對比](../advanced/inline-diff.md)）。
- **批次加標籤（`⌘ L`）與批次刪除（`⌘ ⌫`）**：
  一鍵為多筆記錄管理標籤，或按 Command + Delete 快速清理無用歷史。

---

## 3. 10 秒防誤刪復原（`⌘ Z`）

手快按錯了 `⌘ ⌫` 把重要記錄刪掉了？完全不用擔心：

- 刪除發生後，介面底部會立即出現一個 **「已刪除，10 秒內按 ⌘ Z 復原」** 的懸浮提示條，並帶有清楚的倒數計時進度。
- 只要在倒數結束前按下 **`⌘ Z`**（Command + Z），剛剛刪除的所有條目就會原封不動地原位恢復，甚至連條目的建立時間和標籤屬性也會完全保留。
- 就算超時了也不用慌，所有被刪除的記錄都會先進入「垃圾桶」分類，隨時可以進去還原。
