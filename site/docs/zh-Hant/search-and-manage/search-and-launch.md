# 全文搜尋與拼音啟動應用

很多剪貼簿工具的歷史記錄越存越多後，常常會出現「搜不出」或「搜尋卡頓」的問題。NookClip 採用了高效能的 SQLite FTS5 本機全文索引技術，即使儲存數萬筆歷史記錄，敲擊鍵盤搜尋也能做到毫秒級極速回應。

---

## 1. 毫秒級全文搜尋

叫出面板後，直接敲鍵盤輸入任何關鍵字：

- **中英文混合匹配**：支援中文詞彙、英文程式碼片段、網址 URL、檔案名稱等無縫搜尋。
- **視覺醒目顯示**：匹配到的關鍵字在中間列表的摘要卡片和右側預覽區會同步以醒目的黃色底標出，一目了然。
- **自訂別名優先搜尋（`⌘ R`）**：
  如果你經常使用某些高頻長文字（如一條很長的 SQL 語句、一段範本信件或公司統編抬頭），可以選中該條目後按下 **`⌘ R`**（Command + R），為其設定一個簡短的自訂別名（如 `開票資訊`）。設定後，只要輸入別名就能瞬間定位到該條目。

---

## 2. 拼音極速啟動應用程式（App Launcher）

NookClip 不僅是一個剪貼簿工具，還兼具輕量級應用啟動器的能力。日常不需要頻繁叫出 Spotlight 或 Raycast，在 NookClip 內部就能一步搞定。

### 怎麼使用：

1. 按 `⌘ ⇧ V` 叫出面板。
2. 輸入本機已安裝應用的名稱或**中文拼音首字母**：
   - 輸入 `wx` → 自動匹配 **微信 (WeChat)**
   - 輸入 `zd` → 自動匹配 **終端機 (Terminal)**
   - 輸入 `sf` → 自動匹配 **Safari**
   - 輸入 `code` → 自動匹配 **Visual Studio Code**
3. 列表首項會出現帶有專屬應用圖示的啟動卡片，直接按 **`⏎` (Return)** 即可瞬間喚醒該應用並切換至前台。
