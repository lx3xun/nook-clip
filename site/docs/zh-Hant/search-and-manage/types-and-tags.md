# 類型篩選與標籤管理

除了按時間倒序翻閱和按關鍵字全文搜尋，NookClip 還提供了強大的 **類型槽位** 與 **自訂標籤系統**，幫助你把日常積累的大量片段整理得井井有條。

---

## 1. 8 大固定類型槽位

NookClip 的頂部篩選列包含 8 個固定槽位，按業務屬性分類且排列位置固定不變，不會因為內容數量增減而出現跳動：

1. **收藏（Star）**：加星號的重要內容（收藏內容永久保留，絕不會被筆數上限淘汰）。
2. **圖片（Image）**：截圖、照片與圖形檔案。
3. **文字（Text）**：日常文字段落與排版內容。
4. **連結（Link）**：網址 URL（自動支援預覽區直接生成 QR Code 掃碼打開）。
5. **程式碼（Code）**：程式碼片段與腳本，支援自動語法醒目顯示。
6. **檔案（File）**：從 Finder 複製的檔案物件（如檔案已刪除，會有醒目的失效警示）。
7. **色碼（Color）**：十六進位顏色值（如 `#1677FF`），直接顯示色塊，一鍵複製 RGB/HEX。
8. **垃圾桶（Trash）**：被刪除的內容會暫存這裡，隨時可以還原或徹底清空。

### 全鍵盤快速切換類型

- 按 **`⌘ ]`**（Command + 右中括號）：切換到下一個有內容的類型。
- 按 **`⌘ [`**（Command + 左中括號）：切換到上一個有內容的類型。
- **自動跳過空分類**：如果某個分類下沒有任何記錄，鍵盤切換時會自動跳過，避免停留在空白頁。

---

## 2. 展開與收起篩選面板（`⌘ ↓`）

- 按下 **`⌘ ↓`**（Command + 下方向鍵），即可在搜尋框下方展開完整的篩選面板（或收起面板）。
- 按下 **`⌘ F`**（Command + F），可以直接聚焦搜尋框並自動展開該篩選面板。
- 面板展開後，你可以清楚看到每個分類下的條目數量統計，以及下方的標籤流。

---

## 3. 自訂標籤（Tags）

標籤系統適合用來橫向組織跨類型的內容，例如給一段程式碼和一個網址同時加上 `#專案A`。

### 如何給記錄加標籤：
1. 選中任意一筆記錄。
2. 按下快捷鍵 **`⌘ L`**（Command + L）。
3. 彈出標籤編輯浮層，輸入標籤名稱並按 Return 即可新增（支援一筆記錄加上多個標籤）。

### 標籤與類型的疊加篩選：
在篩選面板的下方，會列出你建立過的所有標籤流。
- 你可以單獨點擊某一個標籤只看相關內容。
- 也可以**與上方類型槽位疊加**：例如先選中【連結】類型，再在下方點擊 `#常用` 標籤，瞬間篩選出所有標記為常用的網址。

### 退格鍵快速移除篩選（`⌫`）：
當搜尋框聚焦且內容為空時，連續按退格鍵 **`⌫`**，系統會智慧地**由內到外逐層移除過濾條件**：
1. 第一次按 `⌫`：先移除當前生效的自訂標籤；
2. 第二次按 `⌫`：移除當前生效的類型分類，回到全量列表。
無需用滑鼠去點關閉小叉，鍵盤流一氣呵成。
