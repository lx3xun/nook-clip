CORE CAPABILITIES

围绕一个主循环精心打磨

呼出 → 检索 → 判断 → 一次粘贴。每个细节都为缩短操作时间而设计。

极致轻量与零等待

底层采用 Rust 存储引擎（SQLite WAL + FTS5 全文索引）与 SwiftUI 原生界面。无 Chromium 内核，常驻内存仅 ~20 MB，按下 ⌘⇧V 零延迟呼出，失焦或按 Esc 自动隐退。

终端安全粘贴护栏

识别 Terminal、iTerm2、Warp、Ghostty 及 VS Code / Cursor 内置终端等 40+ 款终端，多行命令与 sudo、rm -rf 等高危指令先弹窗确认，单行命令自动去除末尾回车防误执行。

两条记录行内对比

选中两条按 ⌘D 即刻呈现行级与字词级红绿差异（支持行内 / 左右 / 只看差异三种视图），对比中可按 ↑↓ 实时换条并直接合并粘贴。

验证码提纯与粘完即焚

复制验证码短信自动提纯为纯数字（如 482910），⌘V 直接贴出验证码；密码、API 密钥等敏感内容粘贴一次后约 0.3 秒自动清空剪贴板，未粘贴则按倒计时自动擦除。

代码、JSON 与色值富预览

代码自动语法高亮，JSON 卡片一键切换「原文 / 美化 / 压缩」；识别颜色值（如 #1677FF）直观展示色标并转换 HEX / RGB，已删文件路径在粘贴前主动提醒。

打字即搜与拼音启动应用

呼出面板直接敲字即可毫秒级全文检索，复制表格或收件信息还能一键按字段拆入顺序粘贴栈；输入拼音首字母（如 wx 找微信、zd 找终端）回车直接打开应用。

PRIVACY FIRST

默认本地、绝不上报的隐私底线

剪贴板往往包含你最敏感的密码、密钥和私聊信息。我们深知守住边界的责任。

01

零数据采集与遥测

无用户账号体系，无用户行为分析（Analytics），无崩溃静默回传。代码全部开源，任何人都可以自行审查网络请求行为。

02

敏感凭证落盘加密

识别到的 API 密钥与连接串，存入本地数据库时自动使用 AES-256-GCM 强加密，加密主密钥受本地文件系统 0600 权限与系统钥匙串严格保管。

03

敏感隔离与内存级脱敏映射

敏感信息绝不写入 FTS5 搜索索引，也不会上传 iCloud。使用 ⌃⏎ 语义脱敏粘贴时，占位符与真实值的映射表只驻留内存、绝不落盘，闲置 30 分钟自动销毁。

04

全透明本地文件路径

数据全部透明保存在用户目录中，可随时备份、迁出或彻底销毁：

~/Library/Application Support/com.lx3xun.nookclip/

首次打开与权限说明（开源 Ad-hoc 签名版本）

本开源版本采用本地签名，未接入苹果每年付费的公证体系。首次启动若遇到 macOS Gatekeeper 拦截，请按以下方式快速通行：

1. 提示「无法打开，因为无法验证开发者」：在访达（Finder）中找到 /Applications/NookClip.app，按住 Control 键点按（或右键）选择「打开」，并在弹出确认窗中点击「打开」即可。
2. 提示「已损坏，移到废纸篓」：打开终端（Terminal）粘贴运行以下命令清除下载属性即可恢复正常：
xattr -cr /Applications/NookClip.app
3. 辅助功能权限（自动粘贴必需）：前往「系统设置 → 隐私与安全性 → 辅助功能」勾选开启 NookClip。
