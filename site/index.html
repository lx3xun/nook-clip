CORE CAPABILITIES

围绕一个主循环精心打磨

呼出 → 检索 → 判断 → 一次粘贴。每个细节都为缩短操作时间而设计。

极致轻量与零等待

底层采用 Rust 高性能存储引擎（SQLite WAL 模式与 FTS5 全文索引），前端使用 SwiftUI 原生构建。没有庞大的 Chromium 内核，常驻内存仅约 20 MB，按下快捷键无缝瞬间呼出。

  • 原生 macOS 悬浮交互，失去焦点或 Esc 自动隐退
  • 无感知后台静默监听，永不打断当前应用敲击

敏感凭证自动脱敏与防护

自动识别复制的 OpenAI、AWS、GitHub Token、私钥与数据库连接串。存盘采用 AES-256-GCM 本地加密，列表中使用掩码遮罩显示，30 秒后自动重锁。

  • 敏感条目绝不写入全文搜索索引，开启同步时自动排除
  • 支持 1Password 等密码管理器黑名单，切到前台静默暂停记录

打字即搜与离线 OCR

呼出面板后无需专门聚焦搜索框，直接敲击键盘即可实时搜索。基于系统原生 Vision 离线识别截图文字，不仅可以直接搜截图里的报错信息，还能一键提取图内文字。

代码与 JSON 专属卡片

复制的代码自动高亮着色；识别到 JSON 数据自动提供树形格式化，支持一键美化、压缩与字段复制，不用再专门打开在线格式化工具。

设计师实用辅助

识别到十六进制颜色值（如 #1677FF）在列表中直观呈现色标，一键复制 HEX / RGB；识别链接自动生成二维码，手机随扫随开。复制的文件若已被删除，粘贴前明确警示。

拼音快速启动应用

不仅能找历史，还能直接当作轻量启动器。在搜索栏键入拼音首字母（如输入 wx 找微信、zd 找终端），回车直接打开应用，无需额外切换工具。

PRIVACY FIRST

默认本地、绝不上报的隐私底线

剪贴板往往包含你最敏感的密码、密钥和私聊信息。我们深知守住边界的责任。

01

零数据采集与遥测

无用户账号体系，无用户行为分析（Analytics），无崩溃静默回传。代码全部开源，任何人都可以自行审查网络请求行为。

02

敏感凭证落盘加密

识别到的 API 密钥与连接串，存入本地数据库时自动使用 AES-256-GCM 强加密，加密主密钥受本地文件系统 0600 权限与系统钥匙串严格保管。

03

敏感内容索引隔离

被标记为敏感的信息绝不写入 FTS5 全文搜索明文索引。如果你主动开启了个人的 iCloud Drive 同步，敏感内容也会被严格限制在本地设备内。

04

全透明本地文件路径

数据全部透明保存在用户目录中，可随时备份、迁出或彻底销毁：

~/Library/Application Support/com.lx3xun.nookclip/

首次打开与权限说明（开源 Ad-hoc 签名版本）

本开源版本采用本地签名，未接入苹果每年付费的公证体系。首次启动若遇到 macOS Gatekeeper 拦截，请按以下方式快速通行：

1. 提示「无法打开，因为无法验证开发者」：在访达（Finder）中找到 /Applications/NookClip.app，按住 Control 键点按（或右键）选择「打开」，并在弹出确认窗中点击「打开」即可。
2. 提示「已损坏，移到废纸篓」：打开终端（Terminal）粘贴运行以下命令清除下载属性即可恢复正常：
xattr -cr /Applications/NookClip.app
3. 辅助功能权限（自动粘贴必需）：前往「系统设置 → 隐私与安全性 → 辅助功能」勾选开启 NookClip。
